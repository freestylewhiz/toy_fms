# 리소스 모델 후속 논의

현재 모델은 [current/resource-model.md](../current/resource-model.md)에 정리했다. 이 문서는 아직 확정하지 않은 확장 방향만 관리한다.

## 미확정 주제

- map registry를 별도 영속 엔티티로 만들고 map 삭제·버전·참조 무결성을 관리할지
- 일반 리소스에도 명시적인 전역 `map_id`를 저장할지
- 편집 DB와 공용 운영 DB를 장기적으로 하나의 저장소 체계로 통합할지
- 사이트·시설·층을 포함하는 상위 소속 모델을 둘지
- 리소스 ID의 사이트별 namespace와 마이그레이션 규칙
