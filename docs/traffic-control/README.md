# 트래픽 존과 주행 정책

기준일: 2026-09-18

상태: **구현 완료, 사용자 검토 대기**

이 디렉터리는 사용자가 편집하는 트래픽 존과 가상 로봇의 주행 판단을 위한
정책 기준이다. 현재 코드가 이미 제공하는 동작과 앞으로 구현할 동작을 혼동하지
않도록, 구현 현황은 각 문서의 `현재 상태` 표기로 확인한다.

## 문서 순서

1. [존 정의](zones.md): 각 존의 목적, 허용 범위, 겹침 우선순위
2. [주행 정책](driving-policy.md): 로봇 크기를 반영한 경로 계획과 추종 규칙
3. [구현 기준](implementation-guide.md): 코드 변경 지점과 검증 조건
4. [로봇의 길 찾기 이야기](robot-road-story.md): 아이와 초심자를 위한 그림 설명

## 핵심 원칙

- 경로는 선이 아니라 **회전하는 로봇 몸체의 이동 궤적**이다.
- `blocked`는 절대 제약이고, `prefer`와 `avoid`는 경로 선택을 유도하는
  소프트 제약이다.
- `prefer`는 존의 내부 중심 경로를 우선한다.
- `avoid`는 존을 완전히 피할 수 없을 때 가장자리의 얕은 사용을 먼저 허용하고,
  깊은 내부 통과는 가장 늦게 선택한다.
- 예약, 점유, 로봇 간 우선순위는 존 비용과 별도의 트래픽 제어 문제다.

이 기준을 바꾸려면 이 문서와 관련 카드의 설명 스냅샷을 함께 갱신한다.
