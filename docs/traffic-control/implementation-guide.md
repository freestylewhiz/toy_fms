# 구현 기준과 검증 조건

## 1. 구현 범위

카드 21은 다음을 구현 대상으로 한다.

1. 로봇 몸체·안전 여유를 반영한 정적 경로 후보 검사
2. `prefer`의 내부 중심 유도 비용
3. `avoid`의 침범 깊이와 경계 완충 비용
4. 비용을 보존하는 경로 단순화와 기본 코너 완화
5. 존 배치와 다중 로봇 주행의 회귀·통합 검증

정밀 시공간 예약, 기종별 동역학 모델, ORCA류 상호 회피는 이 범위에 포함하지
않는다. 후속 카드에서 별도로 다룬다.

## 2. 구현 불변 조건

- 하드 존과 정적 장애물의 안전성은 소프트 존 보상으로 완화되지 않는다.
- 비용장은 로봇 중심점이 아니라 로봇 몸체와 존 경계의 관계를 기반으로 한다.
- 폭이 부족한 선호 존은 경로를 불가능하게 만들지 않는다.
- 회피 존 안의 목표도 접근할 수 있어야 한다.
- 경로 단순화·코너 완화 뒤에도 원래 비용·안전 검사를 다시 수행한다.
- 맵 크기가 큰 경우에도 비용장 생성과 탐색이 예측 가능한 메모리 한도 안에서
  동작해야 한다.

초기 수치는 [주행 정책](driving-policy.md#51-2026-09-18-구현-기준값)의 단일 상수
집합을 사용한다. 구현 중 별도 매직 넘버를 추가하지 않는다.

## 3. 권장 코드 책임

| 책임 | 예상 위치 | 역할 |
| --- | --- | --- |
| 존 거리·비용장 | `shared/semanticNavigation.ts` | 다각형 경계 거리와 prefer/avoid 비용 생성 |
| 전역 탐색·단순화 | `shared/planner.ts` | 비용 누적, 안전한 선분 선택, 곡선화 전 검사 |
| 몸체·장애물 검사 | `shared/occupancy.ts`, `shared/obstacles.ts` | 실제 자세와 이동 구간의 충돌 검사 |
| 경로 추종 | `virtual-robot/src/controller.ts` | 회전 상한·완화 경로 추종·동적 재계획 |
| FMS 중재 | `server/src/traffic/` | 점유, 대기, 재계획 요청의 결정 |

## 4. 완료 검증

### 단위 검증

- 넓은 `prefer` 사각형에서 경로가 경계보다 내부 중심에 형성된다.
- 인접한 `prefer`·`avoid` 존에서 공통 경계를 따라 달리지 않는다.
- `avoid`를 피할 수 있으면 우회하고, 과도한 우회보다 얕은 가장자리 통과가
  합리적인 경우에는 그 경로를 선택한다.
- 좁은 선호 존과 `avoid` 내부 목적지가 경로 불능을 만들지 않는다.
- `blocked`의 기존 몸체 여유 검사는 유지된다.

### 통합 검증

- 카드 21의 첨부 화면과 동등한 존 배치에서 경로와 로봇 몸체의 최소 경계 거리를
  기록한다.
- 코너 구간에서 몸체가 정적 장애물이나 하드 존을 침범하지 않는다.
- 두 로봇이 접근·교차할 때 몸체가 겹치지 않고, 대기와 재계획이 반복 진동하지
  않는다.
- 기존 `local_plan_v1`과 `corridor_lease_v0` 기본 동작을 회귀 시험한다.

## 5. 구현 전 확인할 결정

- 기본 안전 여유와 기본 최소 회전 반경의 수치
- `prefer` 보상과 경로 거리의 상대 가중치
- `avoid`의 얕은 사용과 긴 우회의 비용 균형
- 존 겹침을 편집 UI에서 경고만 할지, 저장 전에 막을지
