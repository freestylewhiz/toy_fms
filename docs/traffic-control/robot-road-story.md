# 로봇의 길 찾기 이야기 🚗

> **누구를 위한 글인가요?** 다섯 살 아이도, 처음 FMS를 쓰는 운영자도 볼 수 있는 설명입니다.

## 로봇의 오늘 할 일

작은 주황 로봇은 파란 동그라미 **A**에서 보라 동그라미 **B**까지 가야 해요.

![파란 A에서 보라 B까지, 초록 길 한가운데를 지나 노랑·빨강 구역을 피하는 작은 주황 로봇](/docs/traffic-control/images/robot-road-story.png)

그림에는 세 가지 특별한 땅이 있어요.

| 땅의 색 | 로봇이 생각하는 말 | 진짜 뜻 |
| --- | --- | --- |
| 🟩 초록 | “여기는 걷기 좋아!” | `prefer` — 가능하면 이 존의 **가운데**를 써요. |
| 🟨 노랑·주황 | “여기는 되도록 비워 둘래.” | `avoid` — 피할 수 있으면 돌아가고, 꼭 지나야 하면 **가장자리로 짧게** 가요. |
| 🟥 빨강 벽돌 | “여기는 절대 안 돼!” | `blocked` / `forbidden` — 절대로 들어가지 않아요. |

## 로봇은 어떻게 생각할까요?

### 1. 먼저, 빨간 곳에는 X 표시해요

로봇은 자기 몸이 닿을 만큼 넉넉한 공간이 있는지 먼저 봐요.

빨간 벽이나 금지 구역에는 로봇의 바퀴나 몸이 조금이라도 닿으면 안 되어요.
그래서 빨간 곳 주변도 가까이 가지 않는 길만 남겨요.

```text
빨간 곳:  절대 안 가요. 🚫
```

### 2. 초록 길에서는 가운데를 찾아요

초록 길 가장자리는 풀숲 옆이라 좁아 보여요.
그래서 로봇은 초록 길 안에서도 **가운데의 밝은 부분**을 더 좋아해요.

```text
초록 길 가장자리  →  괜찮아
초록 길 한가운데  →  제일 좋아! 💚
```

초록 길이 너무 가늘어서 로봇 몸이 편하게 들어갈 수 없다면, 로봇은 억지로
가운데에 끼어들지 않아요. 안전한 다른 길을 찾아요.

### 3. 노랑 길은 정말 필요할 때만 써요

노랑·주황 구역은 사람들이 비워 두고 싶은 곳이에요.

로봇은 먼저 바깥길을 찾아봐요. 그런데 아주 멀리 돌아가야 한다면, 노랑 구역의
**가장자리**를 살짝 지나갈 수 있어요. 한가운데를 길게 가로지르는 것은 싫어해요.

```text
노랑 바깥길       →  좋아요 🙂
노랑 가장자리      →  꼭 필요하면 괜찮아요
노랑 한가운데      →  되도록 하지 않아요 🙅
```

## “초록으로 갈까? 노랑을 피할까?”

로봇은 처음부터 한 가지 길만 고르고 고집하지 않아요.
작은 칸칸마다 점수를 매겨서 여러 길을 비교해요.

```mermaid
flowchart LR
  A[출발 A] --> B[빨간 곳은 지워요]
  B --> C[초록 가운데에는 좋은 점수]
  C --> D[노랑 안쪽에는 나쁜 점수]
  D --> E[점수가 가장 좋은 길]
  E --> F[도착 B]
```

로봇이 보는 점수는 아주 쉽게 말하면 이래요.

```text
짧은 길                → 좋은 점수
초록 길 한가운데       → 더 좋은 점수
노랑 길 한가운데        → 나쁜 점수
빨간 길                 → 아예 고를 수 없음
```

그래서 **조금 더 길어도 편한 초록 가운데 길**을 고를 수 있고,
**엄청 멀리 돌아가는 것보다 노랑 가장자리를 짧게 지나가는 길**을 고를 수도 있어요.

## 마지막으로, 모서리를 둥글게 만들어요

네모난 길은 로봇이 갑자기 “휙!” 하고 꺾어야 해서 불편해요.

로봇은 안전한 공간이 충분하면 모서리를 작은 둥근 길로 바꿔요.
둥글게 돌다가 벽이나 빨간 곳에 닿을 것 같으면, 원래 안전한 길로 가고 천천히 돌거나
제자리에서 방향을 바꿔요.

```text
뾰족한 꺾기  └  →  가능하면 둥근 꺾기  ◜
```

## 친구 로봇을 만나면요?

다른 로봇이 길을 쓰고 있으면 먼저 멈춰서 기다리거나 새 길을 다시 찾아요.
서로 밀고 지나가지 않아요.

> **한 줄 약속:** 빨강은 안 가고, 초록은 가운데로 가고, 노랑은 꼭 필요할 때 가장자리로 짧게 가요.
