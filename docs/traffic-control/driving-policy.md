# 로봇 주행 정책

## 1. 목표

자연스러운 주행은 최단 경로 선을 찾는 것만으로 충분하지 않다. 로봇은 자기 몸체가
지날 수 있는 폭을 유지하고, 선호 존은 안쪽을 사용하며, 회피 존은 깊게 침범하지
않아야 한다.

## 2. 계획 파이프라인

```mermaid
flowchart LR
  A[시작 pose·목표 pose] --> B[몸체 기준 통과 가능 공간]
  B --> C[하드 존·정적 장애물 제외]
  C --> D[prefer/avoid 거리 비용장 생성]
  D --> E[전역 경로 탐색]
  E --> F[회전 반경을 지키는 경로 완화]
  F --> G[몸체·점유·트래픽 재검사]
  G --> H[주행 및 동적 재계획]
```

### 2.1 몸체 기준 통과 가능 공간

전역 계획은 로봇의 길이·폭과 안전 여유를 반영한 구성 공간(configuration space)에서
수행한다. 초기 구현은 외접 반경으로 빠르게 후보를 제거하고, 실제 주행 전과 주행
중에는 회전된 직사각형 몸체로 다시 검사한다.

정적 장애물, 하드 존, 텔레포터 점유 다각형, 동적 상대 로봇은 모두 이 단계의
안전성 검사 대상이다.

### 2.2 소프트 존 비용장

각 후보 자세에는 다음 비용을 계산한다.

| 요소 | 방향 |
| --- | --- |
| 주행 거리 | 짧을수록 좋음 |
| 회전·곡률 | 급격한 방향 전환일수록 불리 |
| `prefer` 내부 여유 | 경계에서 멀고 골격에 가까울수록 유리 |
| `avoid` 침범 깊이 | 깊고 오래 머무를수록 불리 |
| 경계 완충 | 로봇 몸체가 경계를 스칠수록 불리 |

이 값은 연속적으로 변해야 한다. 경계 한 픽셀 차이로 경로가 급격히 바뀌지 않아야
하며, 비용은 경로 전체 길이에 걸쳐 누적한다.

### 2.3 경로 완화와 추종

격자 탐색 결과를 직선으로 단순화하더라도, 단순화한 선분이 소프트 존 비용을
높이거나 몸체 여유를 침범하면 채택하지 않는다.

코너는 최소 회전 반경을 만족하는 호 또는 충분히 짧은 곡선 구간으로 바꾼다.
그 구간 전체에 대해 충돌·하드 존·트래픽 허가를 확인한다. 통과할 수 없는 코너는
더 큰 반경으로 완화하거나 전역 경로를 다시 탐색한다.

## 3. 다른 로봇과의 관계

상대 로봇은 정적 지도와 별도로 동적 장애물로 취급한다.

- 계획 시 두 로봇의 몸체 크기와 추가 안전 여유를 합친 거리로 후보를 배제한다.
- 주행 중에는 다음 이동 구간과 단기 공유 경로를 재검사한다.
- 안전한 진행이 불가능하면 임의로 밀고 들어가지 않고 대기·재계획·FMS 중재를
  따른다.
- 시간에 따른 정확한 충돌 예측, 교차 우선순위, 교착 해소는 현재 `local_plan_v1`
  트래픽 정책의 별도 확장 주제다.

## 4. 정책 경계

- `prefer`는 가능한 경우의 유도이며 임무 성공보다 우선하는 강제 차선이 아니다.
- `avoid`는 통행 금지가 아니다. 통과가 불가피하면 얕고 짧게 사용한다.
- `blocked`는 모든 목적보다 우선한다.
- 존 비용은 예약이나 점유 권한을 주지 않는다. 용량 존과 FMS 트래픽 정책이 그
  권한을 결정한다.

## 5. 초기 기본값과 향후 설정

### 5.1 2026-09-18 구현 기준값

초기 구현은 현재 가상 로봇의 몸체 길이 16px, 폭 10px을 기준으로 다음 값을 사용한다.

| 항목 | 기본값 | 적용 이유 |
| --- | ---: | --- |
| 몸체 외접 반경 | 약 9.43px | 빠른 격자 탐색에서 회전된 몸체를 보수적으로 표현 |
| 소프트 존 경계 여유 | 2px | 존 경계에 몸체가 붙어 보이는 경로를 줄이는 최소 운용 여유 |
| `prefer` 중심부 기준 | 외접 반경 + 2px | 몸체 전체가 존 안쪽에 자리 잡을 수 있는 폭을 우선 |
| `avoid` 외곽 완충 폭 | 외접 반경 + 2px | 존 밖을 스치며 달리는 경로에도 낮은 회피 비용을 반영 |
| 기본 코너 완화 반경 | 12px | 현재 몸체 길이보다 작지 않은 자연스러운 방향 전환의 시작값 |

하드 존과 정적 장애물에 이미 적용된 안전성 검사는 이 값으로 완화하지 않는다.
코너 완화 반경을 둘 공간이 없으면 충돌하지 않는 경로를 우선하고, 가상 로봇은
필요할 때 저속·제자리 회전으로 안전하게 대체할 수 있다.

값은 하나의 명시적 상수 집합으로 관리한다. 카드 21의 통합 시험에서 우회 길이가
과도하거나 좁은 존에서 불안정하면 수치와 근거를 갱신한다. 초기 단계에서는 편집
UI에 이 매개변수를 노출하지 않는다.
