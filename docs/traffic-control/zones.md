# 트래픽 존 정의

## 1. 적용 범위와 용어

트래픽 존은 맵 위의 다각형과 `kind`로 표현한다. 모든 판단은 로봇 중심점 하나가
아닌 현재 자세에서 회전된 로봇 몸체(`footprint`)를 기준으로 한다.

- **하드 존**: 위반하면 경로 후보에서 제외한다.
- **소프트 존**: 통과는 가능하되 거리·회전·침범 깊이와 함께 비용으로 비교한다.
- **용량 존**: 여러 로봇의 진입 순서와 점유를 중재한다. 경로 선호도와는 별개다.
- **존 경계 거리**: 로봇 몸체와 다각형 경계 사이의 최단거리다. 로봇 중심점과
  경계 사이 거리가 아니다.

## 2. 존별 목적과 의미

| 종류 | 분류 | 사용자의 의도 | 경로 계획 의미 | 주행 가능 |
| --- | --- | --- | --- | --- |
| `forbidden`, `blocked` | 하드 | 절대 들어가지 말 것 | 몸체와 안전 여유를 포함해 후보에서 제외 | 불가 |
| `prefer`, `priority` | 소프트 유도 | 가능한 이 공간을 사용할 것 | 존의 중심·골격 경로일수록 큰 보상 | 가능 |
| `avoid`, `penalty` | 소프트 회피 | 가능한 이 공간을 사용하지 말 것 | 깊은 내부일수록 큰 비용 | 가능 |
| `speed_limit` | 동작 제약 | 해당 구간의 속도를 제한 | 경로 선택과 별개로 속도 상한 적용 | 가능 |
| `corridor`, `complex`, `release` | 용량 존 | 통로·구역의 동시 사용량을 제어 | 예약, 점유, 대기열로 진입 중재 | 허가 시 가능 |

`rail`, `portal`, 방향 속성 등 편집 가능한 리소스는 이 문서만으로 실행 보장이
생기지 않는다. 실행 정책으로 채택된 항목만 로봇 행동에 반영한다.

## 3. 공통 우선순위

1. 로봇 몸체의 정적 장애물 충돌과 `blocked` 침범을 먼저 배제한다.
2. 현재 트래픽 정책의 정지·예약·점유 제약을 적용한다.
3. 남은 후보 중 거리, 회전, `prefer` 보상, `avoid` 비용을 합산해 고른다.
4. 최종 추종 경로가 회전 반경과 몸체 여유를 만족하는지 다시 확인한다.

따라서 `prefer`는 `blocked`를 통과하게 만들 수 없고, `avoid`는 물리 장애물처럼
경로를 단절시키지 않는다.

## 4. `prefer`: 내부 중심을 이용하는 존

`prefer`는 단순히 폴리곤 안에 들어가면 동일한 보상을 주는 영역이 아니다.
로봇 몸체가 존 경계에서 멀수록 더 좋은 주행 공간이다.

```text
경계 부근 ───────── 내부 중심·골격 ───────── 경계 부근
낮은 선호                 가장 높은 선호              낮은 선호
```

- 직사각형 존에서는 폭의 중앙선이 자연스러운 주행 경로다.
- L자·다각형 존에서는 도형의 산술 중심이 아니라, 경계에서 가장 멀리 떨어진
  내부 골격 경로를 선호한다.
- 존의 폭이 로봇 몸체와 기본 여유를 수용하지 못하면 중심 경로를 강제하지 않는다.
  이때는 선호 보상을 줄이거나 일반 경로로 통과할 수 있다.
- `prefer`는 차선 강제가 아니다. 지나치게 긴 우회, 하드 존, 예약 불가 상태보다
  우선하지 않는다.

## 5. `avoid`: 얕은 사용부터 허용하는 존

`avoid`는 가능한 비워 두어야 할 공간이다. 다만 목적지 접근이나 과도한 우회를
피하기 위해 통과 자체는 허용한다.

```text
존 밖 → 경계의 얕은 사용 → 내부 깊은 사용 → 중심부 통과
낮은 비용       낮은 회피 비용       높은 회피 비용       가장 높은 비용
```

- 존을 피하는 적절한 길이의 경로가 있으면 그것을 선택한다.
- 완전 우회가 지나치게 길면 경계 부근의 짧은 사용을 먼저 선택한다.
- 존의 중심부를 길게 가로지르는 경로는 가장 불리하다.
- 경계와 접하는 로봇 몸체가 화면상 경계를 스치는 것을 막기 위해, 경계 바깥과
  안쪽 모두에 완만한 완충 비용 띠를 둔다. 이는 진입 금지가 아니다.

## 6. 존 겹침과 목적지 예외

- 하드 존은 언제나 최우선이며 다른 존이 상쇄할 수 없다.
- `prefer`와 `avoid`가 겹치면 `avoid`의 회피 비용과 `prefer`의 내부 보상을 모두
  적용한다. 편집 단계에서 이런 겹침을 경고할 수 있지만 자동으로 삭제하지 않는다.
- 목적지가 `avoid` 안에 있으면 접근을 허용한다. 목적지 부근의 불가피한 침범은
  정상 동작이며, 진입 경로는 가능한 얕은 방향을 택한다.
- 목적지가 하드 존 안에 있으면 명령을 거절하거나 안전한 위치로 명시적으로
  보정해야 한다. 조용한 통과는 허용하지 않는다.

## 7. 현재 상태

`blocked`에는 몸체 여유를 적용한다. `prefer`·`avoid`에는 로봇 외접 반경과 2px
경계 여유를 포함한 연속 거리 비용을 적용한다. 넓은 선호 존의 내부 중심은 낮은 비용,
회피 존의 깊은 내부는 높은 비용이며 좁은 선호 존은 통행 불가로 바꾸지 않는다.
