# 존 유형

모든 존은 맵 픽셀 위 **폴리곤(또는 캡슐 체인)** 이다.
FMS가 기하를 발명하지 않는다. 사용자가 그린 도형이 자원이다.

공통 필드 (스케치):

```
TrafficZone {
  id, name
  kind: corridor | complex | forbidden | avoid | prefer
  polygon: Point[]
  // kind별
  capacity?: number          // corridor, complex
  rail?: Point[]             // corridor: 지정 추종 경로 (optional)
  cost_scale?: number        // avoid > 1, prefer < 1
}
```

---

## 1. `corridor` — 긴 복도

**문제**: 1대만 지나가거나, 2대가 아슬하게 스칠 수 있는 길.
자율 A*는 우회를 만들지 못하고, 한가운데 교착 → 후진이 된다.

**문법**

| 속성 | 기본 | 의미 |
|------|------|------|
| `capacity` | 1 | 동시에 존 안에 있을 수 있는 로봇 수 |
| `rail` | 없음 | 있으면 **추종 모드**. 없으면 용량만 지키고 안에서는 짧은 자율 |
| `portals` | 폴리곤과 외부 자유공간의 접점 | 토큰은 포탈에서만 요청 |

**용량 1**: 반대 방향 정면. 안에 있는 동안 다른 대는 포탈 밖에서 대기.
**용량 2 + rail 두 줄**: 아슬한 교행. 각자 자기 레일만 탄다. 레일을 벗어나면 안 된다.
**같은 방향**: 콘보이. 앞 차와의 간격만. 새 A* 하지 않음.

여기에서는 v0의 F1(경로 이탈)을 **규칙으로 끈다**.
존 안에서는 레일 위가 맞다고 선언했으므로, 경로 권한·추종이 다시 성립한다.
전 맵을 레일로 만드는 것이 아니다.

비상: 이미 두 대가 들어가 버렸으면 VACATE(trail 후진)는 안전망일 뿐, 기본 전략이 아니다.

---

## 2. `complex` — 복잡한 영역

**문제**: 사람이 많거나, 시야·회전이 나쁘거나, 작업 존이라 기하 폭과 무관하게 한 대씩만 넣고 싶다.

**문법**: `capacity = 1` 뮤텍스. **레일 없음**이 기본.
토큰을 가진 로봇은 존 안에서 A→B 자율이 가능하다.
다른 로봇의 로컬 플랜은 존 **밖**에서만 본다. 안에 두 대를 넣지 않으므로 존 내부 교행 규칙을 만들지 않는다.

로비, 도킹 앞, 교차가 꼬인 홀에 쓴다.
`corridor` 와의 차이: 복도는 **형상(폭)** 때문에, complex는 **운영 정책** 때문에 용량을 줄인다.

---

## 3. `forbidden` — 금지 구역

**문제**: 절대 들어가면 안 되는 영역 (안전 펜스, 전시장, 미끄러운 바닥).

**문법**: 계획 occupancy 에서 **lethal**. 벽과 같다.
동적 장애물 회피용으로 비용을 낮춰 통과시키는 옵션은 두지 않는다.
들어갔다면 트래픽이 아니라 고장·수동 개입이다.

UI 장애물(삼각형 등)과 다르다. 장애물은 일시 물체, forbidden은 **맵 정책**이다.

---

## 4. `avoid` — 비선호 구역

**문제**: 지나갈 수는 있지만 가능하면 경로에 넣고 싶지 않다 (소음, 사람 동선, 먼지).

**문법**: A* (또는 Dijkstra) **통과 비용 배율** `cost_scale > 1`.
막지는 않는다. 우회 길이가 `scale` 을 이기면 통과한다.

예: `cost_scale = 3` 이면 그 칸 1px 이동이 자유공간 3px 와 같다.
막다른 골목처럼 유일한 길이면 통과한다. 그게 맞다.

토큰 없음. 여러 대가 동시에 들어가도 FMS가 막지 않는다.
혼잡을 막고 싶으면 `complex` 를 겹쳐 그린다.

---

## 5. `prefer` — 선호 구역

**문제**: 최단이 아니어도 이 통로로 보내고 싶다 (넓은 복도, 바닥 표시, 충전 루프).

**문법**: `cost_scale < 1` (예: 0.4).
**강제 추종이 아니다.** 비용만 낮춰 A*가 그쪽으로 기울게 한다.
막히거나 다른 로봇이 점유하면 더 비싼 길로 빠져도 된다.

Open-RMF 가 lane speed limit 을 비용으로 바꿔 “선호 레인”을 만드는 것과 같다.

일시적 선호(FMS가 분쟁 구간에 잠깐 깔아 주는 힌트 폴리라인)는 사용자 에셋이 아니라 v2 의 **힌트 레이어**다. [`../traffic_control_v2/04_fms_hints.md`](../traffic_control_v2/04_fms_hints.md).

## 플래너에 미치는 효과 요약

| kind | occupancy | A* 비용 | 진입 게이트 | 존 안 모드 |
|------|-----------|---------|-------------|------------|
| forbidden | lethal | — | 없음 (불가) | — |
| avoid | free | × scale>1 | 없음 | 자율 |
| prefer | free | × scale<1 | 없음 | 자율 |
| complex | free | 기본 | 용량 토큰 | 자율 |
| corridor | free | 기본 | 용량 토큰 | 자율 또는 rail 추종 |

비용 맵은 **정적 레이어**(사용자 존)와 **일시 레이어**(FMS 힌트, 상대 시공간 예약)를 더한다.
정적 레이어는 이 문서, 일시 레이어는 v2.
