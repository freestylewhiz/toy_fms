# 테스트 야드 에디터 사용법

브라우저: **http://localhost:5174**
서버·웹·(선택) 가상 로봇을 먼저 켠다. [`README.md`](../../README.md).

## 맵

1600×1200 px, 1 px = 5 cm → **80 m × 60 m**.

- 왼쪽: 큰 직사각 홀
- 오른쪽: 폭 48 px (2.4 m) 가로 복도 + 세로 복도가 만나 **십자 교차로**

휠 = 줌, 스페이스(또는 우클릭) 드래그 = 팬, `0` = 맞춤.

## 세 모드 (위쪽 세그먼트, 또는 키 `1` `2` `3`)

| 모드 | 하는 일 | 안 하는 일 |
|------|---------|------------|
| **운용** | 로봇 선택, Move, Dock, Cancel, Grid 보기 | 맵 에셋 생성 |
| **현장 배치** | 웨이포인트, 충전소, 장애물, forbidden / prefer / avoid | Move / Dock, 그래프 |
| **VDA 배치** | node–edge, station, VDA 존, portal, rail | 로봇 명령, 동적 장애물 |

운용에서 웨이포인트·충전소를 클릭하면 **명령 타깃**이다. 옮기려면 현장 모드 Select.

## 편집 모드 (배치 · 수정)

리소스를 놓거나 고치면 **편집 세션**에 들어간다. 서버에 바로 쓰지 않고, 오른쪽 속성 패널 또는 맵 아래 편집 바에서 **저장 / 취소**한다.

| | 동작 |
|--|------|
| 시작 | 배치 도구로 바닥 클릭, 또는 Select로 기존 리소스 클릭 |
| 시인성 | 편집 중 배경이 살짝 어두워지고, 편집 대상만 밝게 |
| 포즈 (wp/cs/node/station/obstacle) | 중심 드래그 = 이동, **노란 점** = 회전, Q/E = ±15°, `[` `]` = ±5° |
| 존 폴리곤 | 꼭짓점 그린 뒤 닫으면 초안. 라벨·정점 조정 후 확인 |
| 저장 | Enter 또는 **변경 저장 / 저장** 버튼 |
| 취소 | Esc 또는 **취소** 버튼 |

운용 모드 Move/Dock 은 즉시 명령이라 편집 세션을 쓰지 않는다.

## 현장 리소스

| 도구 | 놓는 법 | 고치기 |
|------|---------|--------|
| Waypoint / Charger | 흰 바닥 클릭 → 편집 모드에서 위치·θ 조정 → 확인 | Select로 선택 → 같은 편집 모드 |
| Obstacle | 클릭 → 크기/헤딩 조정 → 확인 | Select 후 편집 |
| Forbidden / Prefer / Avoid | 꼭짓점 클릭. 첫 점/더블클릭/Enter로 닫기 → 확인. Backspace = 마지막 점 취소 | Select 후 라벨·정점·중점 → 확인 |

Prefer의 비용 계수는 1 미만, Avoid는 1 초과를 사용한다. 주행 반영 범위는 [주행 안내](driving.md)를 참고한다.

## VDA 리소스 (맵에 그리는 것)

그래프

- **Node**: 클릭 + 드래그 헤딩
- **Edge**: 시작 노드 클릭 → 끝 노드 클릭. 인스펙터에서 좌/우 회랑 폭(m)
- **Station**: 점 배치. 충전소와 별 객체 (승격은 후속)

존 (`zoneSet` 타입)

BLOCKED, RELEASE, LINE_GUIDED, SPEED_LIMIT, PRIORITY, PENALTY, DIRECTED, BIDIRECTED, COORDINATED_REPLANNING(REPLAN), ACTION

그리는 법은 현장 존과 같다. 닫은 뒤 **확인**으로 저장. Select에서 라벨·정점 조정 후 확인.

보조

- **Portal**: 존을 만든 뒤 두 점으로 초안 생성. 속성 패널에서 이름과 연결 존 확인 후 저장
- **Rail**: 점 여러 개 + Enter로 초안 생성. 선택된 존(없으면 첫 번째 존)을 기본 연결하며 속성 패널에서 변경 가능

`edge.corridor` 는 폴리곤이 아니다. 엣지를 고르고 인스펙터 **L m / R m**.

## 존 폴리곤 편집

시맨틱 존은 좌표 배열(단순 링)로 저장한다. 그리는 문법은 맵 에디터에서 흔히 쓰는 것과 같다.

- **Mapbox GL Draw** `draw_polygon` + `direct_select`: 클릭으로 점, 첫 점/Enter로 닫기. 선택 후 정점 드래그, 변 중점 클릭으로 점 추가, 피처 드래그로 통째 이동.
- **OSM iD**: 같은 정점·중점 핸들. Backspace는 마지막 점만 취소.
- **deck.gl / Terra Draw / Leaflet-Geoman**: 기본값으로 self-intersection(나비 날개) 거부. 접힌 링은 저장하지 않음.

이 에디터도 같다.

1. 그리기 중 고무줄이 빨개지면 그 점은 안 들어간다. Backspace로 직전 점만 지운다. Esc는 초안 전체 취소.
2. 닫힌 존의 **이름 라벨**을 잡아 통째로 옮긴다. 면 내부를 드래그해도 존 전체를 이동할 수 있다.
3. Select로 고르면 흰 사각형(정점)과 변 중간 점(삽입)이 나온다.

저장 시 시계방향이면 반시계로 뒤집는다 (VDA zoneSet 관례).

## 저장

배치한 에셋은 **SQLite** (`data/editor.sqlite`) 에 남는다. 새로고침해도 유지.
로봇 위치는 저장하지 않는다. MQTT / 실기 VDA 송신은 없다.

장애물 생성·반지름·위치 수정은 연결된 가상 로봇의 배치 허용 응답을 확인한 뒤 저장한다. 응답 거부 또는 시간 초과 시 초안을 유지하며 상태 표시줄에 이유를 표시한다. 연결된 로봇이 없으면 해당 투표를 생략한다. DB에서 불러올 때는 투표하지 않는다.


## 속성 패널

왼쪽 목록은 리소스 이름과 종류를 표시하며 이름으로 검색할 수 있다. 맵 또는 목록에서 선택하면 오른쪽 **속성** 탭에서 편집한다.

- 모든 리소스: 생성 전에 **이름** 지정 가능. 고유 ID는 생성 초안에서 자동 부여하고 저장·이름 변경·서버 재시작 후에도 유지한다. 기존 리소스 ID도 유지한다.
- 이름과 숫자 입력은 **초안**에 적용한다. 실시간 로봇 상태 패치가 입력값을 덮어쓰지 않는다. **변경 저장**은 서버의 저장 확인 후 완료하며, **취소 / Esc**는 마지막 저장값으로 되돌린다.
- **θ 게이지**를 좌우로 드래그하거나 도(°) 단위 숫자를 입력한다. 라디안 값을 함께 표시하며 저장 규격은 rad이다. 존은 면적 중심, 레일은 정점 평균을 기준으로 형상이 회전한다. 엣지 θ는 헤딩 속성이며 연결 노드를 이동시키지 않는다.
- 위치는 px 단위로 입력한다. 존의 X/Y는 면적 중심을 이동하며 모든 정점을 함께 이동한다.
- 원형 장애물은 **반지름**, 사각형은 **반폭**, 삼각형은 **외접 반경**을 입력한다. 단위는 px이며 1 px = 0.05 m이다.

| 리소스 | 추가 편집 값 |
| --- | --- |
| Prefer / Avoid / Priority / Penalty | 비용 계수 |
| Corridor / Complex | 수용 용량 |
| Speed limit | 최대 속도(m/s) |
| Directed / Bidirected | 통행 방향(rad), 방향 제한 |
| Release | 권한 해제 시 동작 |
| Node | 위치·각도 허용 오차 |
| Station | 용도(charger / pick_drop / wait / other) |
| Edge | 최대 속도, 좌우 회랑 폭(m) |
| Portal / Rail | 연결 구역 |

**형상 및 연결 정보**에서는 고정 ID, 맵, 위치 또는 중심, 폴리곤 면적, 정점 수와 좌표, 연결 노드/구역 및 기존 액션·대기 위치 정보를 확인한다. 정점 모양은 맵의 정점·중점 핸들로 편집한다.

기존 존은 편집 중에도 **삭제 버튼 / Delete**로 전체 삭제할 수 있다. 삭제 전 확인창에서 이름·종류·ID를 확인한 뒤 **삭제**를 눌러야 실제 반영된다. **취소 / Esc**는 선택과 입력 중인 초안을 유지한다. 확인창의 최초 포커스는 취소이며, 다중 선택도 한 번의 확인창에 삭제 대상을 함께 표시한다. Backspace는 선택한 정점을 삭제하며 최소 3개를 유지한다. 생성 중인 미저장 초안은 취소로 제거한다.

UI 회귀 검사: `bun run check:properties:web` (서버·웹·가상 로봇 실행 후). 검사에서 생성한 리소스만 정리한다.


## Atlas Studio 작업 공간

- **왼쪽 탐색기**: 현재 맵 미리보기, 접이식 맵 전환, 이름/ID 검색, 현장·구역·그래프 종류 필터. `/`로 검색에 바로 진입한다.
- **위쪽 도구**: 운용 / 현장 배치 / VDA 배치에 맞춰 도구를 표시한다. VDA 도구는 그래프 / 구역 규칙 / 포털·레일 하위 메뉴로 나눈다. **Ctrl/⌘ K**로 도구를 검색하고 Enter로 실행하면 해당 모드로 전환된다.
- **중앙 지도**: 기본 청사진 스타일. 하단 **청사진** 버튼으로 원본 도면과 전환한다. 미니맵 클릭은 해당 위치로 이동하고, 미니맵에서 Enter 또는 Space를 누르면 전체 맵을 맞춘다.
- **오른쪽 속성**: 선택한 형상의 미리보기와 회전 방향, 이름·위치·각도 및 종류별 필드. 속성 / 레이어 / 로봇 탭으로 작업을 전환한다.
- **집중 모드**: 상단 집중 버튼 또는 **Shift F**로 패널과 도구를 접고 지도를 전체 작업 공간으로 확장한다. 다시 실행하면 원래 패널 구성으로 복원된다.
- 좁은 화면에서는 탐색기·속성 패널을 상단 버튼으로 열고 닫는다.

삭제 확인·속성 저장 검사: `bun run check:properties:web`.
명령 검색·필터·집중 모드·390–1280px 레이아웃 검사: `bun run check:workspace:web`.
