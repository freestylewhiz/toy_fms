# 맵 에디터 테스트 UI — 크롬·인터랙션

순수 HTML/CSS/TS. React 없음. 다크 산업형 콘솔. 라벨은 한국어.

이 문서는 **시각 레이아웃과 조작 문법**만 정합니다. 저장 스키마·서버는 다른 agent 문서에 맡깁니다.

---

## 0. 교체 대상 (현재 UI의 병목)

현 `web-client`는 CAD가 아니라 **고정 캔버스 + 단일 툴바**입니다.

| 항목 | 현재 | 문제 |
|------|------|------|
| 셸 | `52px / 1fr / 32px` × `76px / 1fr / 280px` | 맵이 남는 공간을 쓰지 못함 |
| 캔버스 | `#map` **720×560 CSS px**, 스크롤로만 이동 | 대형 occupancy에 pan/zoom 없음 |
| 툴바 | Select / Waypoint / Charger / **Move / Dock** / Obstacle / Grid | 저작(배치)과 운용(명령)이 한 레일에 섞임 |
| 폴리곤 | 없음. Obstacle은 △□○ 프리미티브 | forbidden / prefer / avoid / VDA zoneSet 불가 |
| 그래프 | 없음 | node–edge, trajectory, edge.corridor 리본 불가 |
| 인스펙터 | 280px, x/y/θ + 장애물 size | 존 필드·엣지 회랑을 담을 수 없음 |
| 아웃라이너 | 없음 | 리소스 수십 개를 클릭으로만 찾음 |

목표: **많이 놓고, 겹쳐 보고, 고치고, 큰 맵을 훑는** 에디터. 클릭 한 번에 끝나는 운용 모드는 유지하되 레일을 분리합니다.

### 1.1 CSS 셸 (구현자가 그대로 쓸 수치)

```
body {
  display: grid;
  grid-template-rows: 48px 1fr 28px;
  height: 100%;
  overflow: hidden;
}

.shell {
  display: grid;
  grid-template-columns: 72px 1fr 340px;
  min-height: 0;
}

.dock-right {
  display: grid;
  grid-template-rows: 240px 1fr;   /* 아웃라이너 고정, 인스펙터가 나머지 */
  min-height: 0;
  border-left: 1px solid var(--line);
}
```

- 뷰포트 최소 권장: 1280×800. 그 이하면 우측 도크는 접힘 버튼(`]`)으로 0px.
- `#map` 캔버스는 **뷰포트 전체를 덮는 CSS 크기** (`width/height = clientWidth/clientHeight`, devicePixelRatio 반영). 월드 크기(예: occupancy 720×560 **픽셀**)는 카메라 행렬로만 다룹니다. CSS로 720×560 박스를 가운데 두지 않습니다.
- 기존 `.map-sizer { padding: 24px; margin: auto }` 패턴은 폐기합니다.

### 1.2 상단바 (`header.topbar`) — 왼쪽 → 오른쪽

| 슬롯 | 너비 | 내용 |
|------|------|------|
| 브랜드 | 자동 | 14px 마크 + `bg_fms · 1st Floor` (15px, 자간 0.04em) |
| **모드 스위치** | 228px | 세그먼트 3칸: `운용` `현장` `VDA`. `role="tablist"`. 선택 칸 `aria-selected="true"` |
| 맵 메타 | 자동 | `mapId` 칩 + `mapVersion`. 클릭 시 인스펙터가 맵 루트를 선택 (편집은 필드만, 픽셀 페인트 없음) |
| 스냅 칩 | 88px | `SNAP` + 현재 간격 (`off` / `1px` / `5px` / `0.25m`). 클릭 순환. `;` 키와 동일 |
| 연결 | 자동 | 기존 `.conn` 점: offline 빨강 / connecting 금 / online 녹 |
| 선택 로봇 | 자동 | `선택 로봇` + `#sel-robot-id`. 운용 모드에서만 강조(teal). 저작 모드에서는 muted |

모드 스위치는 상단 **한곳만** 둡니다. 좌측 레일에 모드 버튼을 중복하지 않습니다.

### 1.3 좌측 레일 (`nav.rail`)

- 너비 **72px**. 세로 스크롤 허용 (`overflow-y: auto`).
- 버튼: 아이콘 22px + 한글 라벨 9px + `kbd` 9px. `aria-pressed`로 활성 도구.
- **그룹 구분선** `.rail-sep` 높이 1px, `--line`, 상하 6px 마진.
- 레일 DOM은 **세 모드 도구를 모두 넣고**, `body[data-mode]` CSS로 숨깁니다. JS로 innerHTML을 갈아끼우지 않습니다 (포커스·단축키 유지).

```css
body[data-mode="ops"]  .rail [data-rail="site"],
body[data-mode="ops"]  .rail [data-rail="vda"]  { display: none; }

body[data-mode="site"] .rail [data-rail="ops"],
body[data-mode="site"] .rail [data-rail="vda"]  { display: none; }

body[data-mode="vda"]  .rail [data-rail="ops"],
body[data-mode="vda"]  .rail [data-rail="site"] { display: none; }
```

공통 도구(`data-rail="common"`)는 세 모드 모두 보입니다.

활성 모드는 레일 **배경 악센트**로 구분합니다.

| 모드 | `data-mode` | 레일 상단 3px 바 | 활성 버튼 액센트 |
|------|-------------|------------------|------------------|
| 운용 | `ops` | `--green` `#34d399` | teal |
| 현장 | `site` | `--gold` `#fbbf24` | gold |
| VDA | `vda` | `--cyan` `#38bdf8` | sky |

### 1.4 뷰포트 HUD (캔버스 위 오버레이, pointer-events 분리)

캔버스는 `touch-action: none`. HUD는 `position: absolute` 자식.

| HUD | 위치 | 역할 |
|-----|------|------|
| 레이어 칩 | 우상, 12px inset | 가시성 토글. §6 |
| Occupancy 범례 | 좌하, 12px | Grid가 off가 아닐 때만 |
| 줌 컨트롤 | 우하 | `−` / 퍼센트 / `+` / `맞춤` |
| 미니맵 | 우하 줌 위, 160×120 | 맵 월드가 뷰포트의 **2배 이상**일 때만 표시. 드래그로 pan |
| 도구 힌트 | 상단 중앙, 도구 진입 2초 후 fade | 예: `클릭으로 정점 · Enter 닫기 · Esc 취소` |
| 검증 플래시 | 캔버스 전체 또는 해당 폴리곤 | §6.2 |

### 1.5 우측 도크

**아웃라이너 (상, 240px, overflow auto)**

- 검색 입력 28px + 트리.
- 그룹: `현장` / `VDA` / `런타임`. 접기 가능.
- 행: 색 점 6px + 종류 약어 + id. 선택 행은 모드 액센트 보더.
- 눈 아이콘: 객체 단위 hide (레이어 토글과 AND).
- 더블클릭: 카메라를 해당 AABB로 `맞춤` (padding 48px).
- 런타임(로봇·동적 장애물·계획 경로)은 **편집 불가** 자물쇠 표시. 선택은 됨(인스펙터 읽기).

**인스펙터 (하, 나머지, overflow auto)**

- 패딩 14px. `h2`는 11px uppercase muted (현 스타일 유지).
- 비선택 시 빈 상태 §6.1.
- 필드 그리드: 라벨 88px + 컨트롤 1fr. 현 18px 라벨 열은 폐기 (필드명이 `allowedDeviationXY`까지 감).
- 숫자 입력 `step`은 px 필드 1, m 필드 0.01, rad 0.01.
- 하단에 위험 버튼 스택: 삭제 / (해당 시) 복제.

### 1.6 상태바 (`footer.statusbar`) 28px, 한 줄

왼쪽: `px` 좌표 · `m` 좌표 (1 px = 5 cm) · 커서 θ(회전 도구일 때) · `zoom %` · 스냅 상태.

오른쪽: 활성 도구 이름 + 진행 상태 (`폴리곤 정점 4 · 미닫힘`) · 마지막 ack/error (`#status-msg`, error=danger, ack=teal).

두 영역 모두 `ui-monospace`, ellipsis.

## 2. 모드 스위치 UX

세그먼트는 **작업 세계**를 바꿉니다. 카메라는 유지합니다. 선택 집합은 모드에 없는 객체를 **유지하되 흐리게** 하고, 인스펙터는 읽기 전용으로 둡니다. 저작 중 실수로 Move를 누르지 못하게 하는 것이 핵심입니다.

### 2.1 전환 규칙

| 전환 | 활성 도구 | 로봇 명령 레일 | 캔버스 커서 기본 |
|------|-----------|----------------|------------------|
| → 운용 | `select` | **보임** Move / Dock / Cancel | 십자 (명령 시) / 포인터 (선택) |
| → 현장 | `select` | **숨김** | 십자 또는 펜 |
| → VDA | `select` | **숨김** | 십자 또는 펜 |

- `body[data-mode]`만 바꿉니다. 라우팅 없음 (순수 HTML).
- 단축키 `1` `2` `3` = 운용 / 현장 / VDA. 입력 포커스가 `input`/`textarea`일 때는 무시.
- 저작 모드에서 Move/Dock 단축키(`M` `D`)는 **바인딩하지 않습니다**. `M`은 운용에서만 Move.
- 운용 모드에서 존·노드를 **새로 배치하는 도구는 없습니다**. 선택은 되고, 드래그 이동은 현장/VDA에서만.

### 2.2 모드별 좌측 레일 (위→아래)

**공통 (`data-rail="common"`)** — 모든 모드 최상단

| 도구 | 라벨 | 키 | 동작 |
|------|------|----|------|
| select | 선택 | `V` | 클릭 선택, 드래그 이동(저작 모드·에셋만), 박스 선택(Shift 없이 드래그가 빈 바닥에서 시작) |
| pan | 이동 | `H` 또는 Space 홀드 | 손바닥. Space는 모멘터리(떼면 이전 도구) |
| rotate | 회전 | `R` | 선택 점 에셋의 θ 핸들. 폴리곤은 바운딩 회전(정점 일괄) |
| vertex | 정점 | `E` | 폴리곤/궤적/레일 정점 편집 |
| measure | 측정 | `I` | 두 점 거리(px·m). 저장 안 함 |
| — | — | — | 구분선 |
| occ | 격자 | `G` | occupancy 3단: off → bin → inflated |

**운용 (`data-rail="ops"`)** — 명령만. 배치 도구 없음

| 도구 | 라벨 | 키 | 동작 |
|------|------|----|------|
| move | 이동명령 | `M` | 로봇 선택 후 웨이포인트 또는 흰 바닥. 클릭-드래그 = 도착 θ |
| dock | 도킹 | `D` | 로봇 선택 후 충전소/스테이션 |
| cancel | 취소 | `Shift+C` | 선택 로봇 주행 취소. 버튼은 인스펙터에도 복제 |

운용 레일 하단은 **비웁니다**. Obstacle을 여기에 두지 않습니다 (현장).

**현장 (`data-rail="site"`)** — 시드·운영자가 그리는 리소스

| 도구 | 라벨 | 키 | 동작 |
|------|------|----|------|
| waypoint | 경유 | `W` | 점 배치. 클릭 후 드래그 = θ |
| charger | 충전 | `C` | 점 배치. 동일 θ 제스처 |
| obstacle | 장애 | `O` | 인스펙터에서 △□○ 선행 선택. 클릭(중심) 후 드래그(크기) |
| — | — | — | 구분선 «존» |
| zn-forbidden | 금지 | `F` | 폴리곤. occupancy lethal |
| zn-prefer | 선호 | `P` | 폴리곤. cost_scale < 1 |
| zn-avoid | 회피 | `A` | 폴리곤. cost_scale > 1 |
| zn-corridor | 복도 | `B` | 폴리곤 + 포탈/레일 서브툴 (용량 존) |
| zn-complex | 복합 | `X` | 폴리곤 + 포탈 (뮤텍스) |

현장 존은 **운영자 언어**입니다. VDA `zoneType` 원형 이름은 VDA 레일에 둡니다. 같은 폴리곤을 두 모드에서 중복 생성하지 않습니다.

**VDA (`data-rail="vda"`)** — 그래프·zoneSet 원형

| 도구 | 라벨 | 키 | 동작 |
|------|------|----|------|
| node | 노드 | `N` | 점 pose. inflated free만 |
| edge | 엣지 | `L` | 시작 노드 클릭 → 끝 노드 클릭. 단방향 |
| traj | 궤적 | `T` | 선택 엣지 위 폴리라인. 없으면 직선 |
| ribbon | 회랑 | `U` | 선택 엣지 left/right 폭 리본 (폴리곤 아님) |
| station | 스테이션 | `C` | 점. kind 아이콘. interaction node 연결 |
| — | — | — | 구분선 «zoneSet» |
| vz-blocked | BLOCKED | | 폴리곤 |
| vz-release | RELEASE | | 폴리곤. 포탈 서브툴 |
| vz-line | LINE_GUIDED | | 폴리곤. 레일 또는 그래프 궤적 연결 |
| vz-speed | SPEED_LIMIT | | 폴리곤 |
| vz-priority | PRIORITY | | 폴리곤 |
| vz-penalty | PENALTY | | 폴리곤 |
| vz-directed | DIRECTED | | 폴리곤 + 방향 화살 |
| vz-bidi | BIDIRECTED | | 폴리곤 + 양방향 화살 |
| vz-replan | REPLAN | | `COORDINATED_REPLANNING` |
| vz-action | ACTION | | 폴리곤. 진입/통과/이탈 액션 |
| — | — | — | 구분선 |
| portal | 포탈 | `[` | 용량/RELEASE 존 경계 위 선분 |
| rail | 레일 | `]` | 존 내부 폴리라인 |

VDA 레일은 항목이 많아 **반드시 스크롤**됩니다. 존 타입은 2열 미니 버튼(36×36)로 밀도만 높이고, 아이콘+2~3글자 약어를 씁니다 (`BLK` `REL` `LINE` `SPD` `PRI` `PEN` `DIR` `BI` `RPL` `ACT`).

### 2.3 서브툴 (레일을 늘리지 않음)

포탈·레일·장애물 형상은 **인스펙터 상단 칩**으로 보조합니다.

- 현장 Obstacle 선택 또는 도구 `O`: 인스펙터 `△ □ ○` (현 `shape-row` 이동. 우측 전용 섹션 폐기).
- 복도/복합 또는 RELEASE/LINE_GUIDED **객체가 선택된 동안만** 인스펙터에 `포탈 추가` `레일 추가` 버튼. 레일 도구를 상시 노출하지 않아도 됩니다. VDA 레일의 portal/rail은 그래프 작업이 많을 때를 위한 명시 도구입니다.

### 2.4 운용에서 숨기는 것 (체크리스트)

저작 모드(`site`/`vda`)에서 DOM은 남기되 보이지 않게 할 것:

- Move, Dock 버튼
- 인스펙터의 `Cancel 주행` (운용에서만)
- 상단바 선택 로봇의 teal 강조는 꺼도 됨 (값은 표시)

운용에서 숨길 것:

- 현장/VDA 배치 도구 전부
- 인스펙터의 존 kind 셀렉트·엣지 폭 슬라이더 등 **편집 컨트롤** (선택 시 읽기 전용 텍스트)

로봇 카드: 운용에서는 인스펙터 **최상단**에 고정. 저작 모드에서는 아웃라이너 `런타임` 그룹으로만. 인스펙터를 에셋 필드에 양보합니다.

## 3. 인터랙션 문법

카메라는 모든 도구에서 공통입니다. 도구는 “다음에 클릭이 무엇을 만드는가”만 바꿉니다.

### 3.0 카메라 (pan / zoom)

| 입력 | 동작 |
|------|------|
| Space + 드래그, 또는 중버튼 드래그, 또는 도구 `H` | pan. 월드 좌표 유지 |
| 휠 | 커서 기준 zoom. 배율 `clamp(0.25, 8.0)`, 스텝 ×1.12 |
| `0` | 맵 AABB를 뷰포트에 contain 맞춤 (padding 32px) |
| `Z` / `Shift+Z` | 현재 선택 AABB 맞춤 / 이전 줌 복귀 없음(맞춤만) |
| Ctrl+휠 | 동일 zoom (트랙패드 습관) |

화면 좌표 → 월드 px: `world = (screen - pan) / zoom`. 상태바는 이 값을 표시합니다.

스냅: 월드 좌표를 격자(기본 1 px, 옵션 5 px 또는 0.25 m = 5 px)로 반올림. **거절과 스냅을 섞지 않습니다.** 흰 바닥이 아니면 스냅하지 않고 거절+플래시 (현 규칙 유지). forbidden 정점은 예외적으로 **벽 픽셀에 붙이기** 스냅 허용.

### 3.1 점 에셋 (waypoint, charger, station, node, 로봇은 읽기)

**배치**

1. 해당 도구 진입. 커서가 고스트 아이콘 (24px, 불투명 0.55).
2. **클릭** = 위치 확정. 마우스 **버튼을 누른 채 드래그**하면 θ. 버튼 업에서 커밋.
3. Shift 홀드 중 배치: θ를 45°(π/4) 스냅.
4. 커밋 후 도구는 **유지** (연속 배치). Esc 또는 `V`로 선택 복귀.

**선택·이동**

- 본체 히트 24px 원. 드래그 = 이동. 고스트를 실시간.
- 노드가 inflated occupancy 밖으로 나가면 드롭 시 거절, 원위치, 빨간 플래시.
- waypoint/charger는 흰 바닥만. station은 노드와 같거나 charger 규칙(합의 §8).

**회전 핸들**

- 선택 + 도구 `R`, 또는 선택 상태에서 본체 위 **Alt+드래그**.
- 에셋 중심에서 반지름 28px 원호 + 끝점 다이아몬드.
- 드래그 중 점선 헤딩. Shift = 45° 스냅.
- 원형 Obstacle은 회전 무시 (현 규칙).

아이콘: waypoint/charger 24px, 로봇 스프라이트 20×16 1:1, 노드는 **12px 원 + θ 바늘** (아이콘 파일 없음, 벡터).

### 3.2 폴리곤 존 (현장 존 + VDA zoneSet)

CAD 폴리라인과 같습니다.

**그리기 (도구 = 존 kind)**

1. 첫 클릭 = 정점 0. 이후 클릭마다 정점 추가. 러버밴드 엣지.
2. **더블클릭** 또는 **Enter** 또는 **첫 정점 8px 안 클릭** = 닫기.
3. 정점 < 3 이면 닫기 거절, 상태바 `정점 3개 이상`.
4. 닫힌 뒤 단순 폴리곤 검사. self-intersection이면 커밋 거부, 교차 엣지를 노랑 플래시.
5. 시계방향이면 **저장 시 CCW로 뒤집음** (캔버스 y-down 계약은 SemanticMap.frame 한곳). 사용자는 방향을 신경 쓰지 않습니다.
6. 맵 AABB 밖 정점 → 거절.
7. 도구 유지로 다음 존 연속.

**선택**

- 변 또는 내부 클릭. 겹치면 **최상위 z** (나중에 그린 것) 또는 Alt+클릭으로 순환.
- 선택 시: 변 2px 강조, 정점 스퀘어 7px, bbox 점선.

**이동**

- 내부 드래그 = 폴리곤 통째 이동 (정점 상대 유지).
- 도구 `R`: bbox 중심 기준 전 정점 회전. Shift 45°.

**정점 편집 (도구 `E` 또는 선택 후 정점 직접 드래그)**

| 제스처 | 동작 |
|--------|------|
| 정점 드래그 | 이동. 스냅 적용 |
| 변 중점 호버 (작은 +) 클릭 | 정점 삽입 |
| 정점 선택 후 Delete / Backspace | 정점 삭제. 남은 정점 < 3 이면 객체 삭제 확인 없이 **존 삭제 거부**, 상태바 안내 |
| Ctrl+클릭 정점 | 다중 정점 선택 후 일괄 이동 |

편집 중 self-intersection이면 변을 점선 빨강, 커밋(마우스 업)은 허용하되 저장/배포 시 §6.2 검증.

### 3.3 노드–엣지 연결 (도구 `L`)

1. 첫 클릭: 히트된 **노드만** 시작. 빈 바닥 클릭은 무시 + 힌트 `노드를 선택하세요`.
2. 러버밴드: 시작 노드 → 커서. 화살촉은 끝 쪽.
3. 둘째 클릭: 끝 노드. 자기 자신이면 거절.
4. 이미 같은 `(start, end)` 가 있으면 거절 (중복 엣지). 역방향은 **별도 엣지**로 허용 (LIF 단방향).
5. 커밋 시 trajectory 없음 = 두 노드 직선. corridor 폭 0 = 리본 없음.
6. Shift+엣지 도구: 끝 노드 커밋 후에도 시작을 끝으로 이어 **폴리라인 체인** (A→B 다음 B→C).

엣지 히트: 중심선에서 6px. 선택 시 화살 + 양 노드 하이라이트.

### 3.4 엣지 궤적 + corridor 리본

**궤적 (도구 `T`, 엣지 선택 필수)**

- 선택 엣지의 중심선을 폴리라인으로 바꿉니다.
- 클릭으로 제어점. Enter 확정. 첫점은 start 노드, 끝점은 end 노드에 **자동 고정** (드래그로 노드를 떼지 않음).
- 정점 도구 `E`로 중간점만 편집.
- 내부 저장은 폴리라인. NURBS export는 이 UI의 문제가 아닙니다.

**리본 (도구 `U` 또는 엣지 선택 시 인스펙터 폭)**

폴리곤 도구가 아닙니다.

1. 중심선 = trajectory 또는 노드 직선.
2. 진행 방향 기준 **왼쪽** `leftWidth`, **오른쪽** `rightWidth` (m). 화면에는 px로 변환 (×20).
3. 반투명 밴드 + 좌/우 외곽 점선.
4. 온캔버스: 리본 좌·우 외곽선의 **중간 너클**을 드래그하면 해당 측 폭만 변경. 양측 동시 = Alt+드래그.
5. 폭 둘 다 0 또는 필드 없음 = 리본을 그리지 않음 (“회랑 없음”).
6. 리본이 벽·BLOCKED/forbidden과 겹치면 겹침 해치 + 저장은 허용, 배포 전 경고.

현장 `zn-corridor` **폴리곤**과 이 리본은 **다른 객체**입니다. 선택 하이라이트 색을 나눕니다 (§4).

### 3.5 포탈 · 레일

**포탈**

- 대상 존(복도/복합/RELEASE)이 선택된 상태에서만.
- 클릭 1: 경계 **위** 점 (경계에서 4px 초과면 거절).
- 클릭 2: 같은 경계 체인 위 둘째 점 → 선분.
- 자동 제안: 도구 진입 시 자유공간과 맞닿는 변을 점선 청록으로 미리 보여 주고, 변 클릭으로 수락.
- 존 **내부 한가운데** 포탈은 커밋 거부 (배치 규칙).

**레일**

- 존 내부에서만 폴리라인. 존 밖 정점은 경계로 클램프 또는 거절.
- 용량 2인 복도는 레일 2개 강제 — 1개만 있으면 저장 거부 플래시.
- 정점 문법은 폴리곤과 동일하나 닫지 않습니다.

### 3.6 동적 장애물 (현장 `O`)

현 규칙 유지: 맵 **아무 픽셀**, 크기 10–80 px, 벽 포함 가능. 로봇 몸체·앞으로 5초 경로를 가리면 서버 거절 + 플래시.

선택 후 본체 드래그=이동, 흰 핸들=크기. 회전은 △□만.

### 3.7 박스 선택 · 다중 선택

- 빈 바닥에서 드래그: 점선 박스. 점이 박스에 들어간 에셋 다중 선택.
- Shift+클릭: 토글 추가.
- 다중 선택 시 인스펙터는 `n개 선택` + 공통 필드만 (예: 일괄 θ). 종류가 섞이면 공통 없음, 삭제만.
- 운용 모드 박스는 로봇만.

### 3.8 커서

| 상태 | CSS cursor |
|------|------------|
| 선택 히트 없음 | `default` |
| 에셋 호버 | `pointer` |
| 이동 드래그 | `grabbing` |
| pan | `grab` / `grabbing` |
| 폴리곤/엣지 그리기 | `crosshair` |
| 회전 핸들 | `alias` 또는 커스텀 회전 |
| 거절 위치 | 커서는 유지, 플래시만 |

호버 시 id 라벨 (현 UI). 드래그 중 고스트.

## 4. 색 시스템 (겹쳐도 읽히게)

바닥 PNG는 그대로 두고, 시맨틱은 **낮은 채움 + 강한 스트로크 + 해치**로 겹칩니다. 솔리드 불투명 칠 금지.

### 4.1 토큰 (`:root` 확장)

현 팔레트를 유지하고 존·그래프만 추가합니다.

```
--bg: #0b1220;
--bg-raised: #0f172a;
--bg-panel: #111827;
--line: #1e293b;
--line-strong: #334155;
--text: #e2e8f0;
--muted: #94a3b8;
--teal: #2dd4bf;     /* 운용 액센트, prefer, free occupancy */
--gold: #fbbf24;     /* 현장 액센트, inflate, charger */
--orange: #fb923c;   /* robot-1, avoid/penalty */
--green: #34d399;    /* online, robot-2 */
--danger: #f87171;
--cyan: #38bdf8;     /* VDA 액센트, 그래프 */
--pink: #f472b6;     /* 동적 장애물 */
--violet: #a78bfa;   /* complex, replan */
```

### 4.2 그리기 규칙 (canvas 2D)

채움 α **0.14**, 스트로크 α **0.90**, 스트로크 1.5px (줌과 무관하게 화면 픽셀 기준으로 그리려면 lineWidth = 1.5 / zoom).

해치는 `createPattern` 8×8.

| 종류 | 채움 | 스트로크 | 해치 |
|------|------|----------|------|
| forbidden / BLOCKED | `#f87171` | `#fb7185` | 대각 `/` 간격 8px |
| avoid / PENALTY | `#fb923c` | `#fdba74` | 점 2px |
| prefer / PRIORITY | `#2dd4bf` | `#5eead4` | 수평 `—` |
| corridor (현장 폴리곤) | `#818cf8` | `#a5b4fc` | 없음. 스트로크 실선 |
| complex | `#a78bfa` | `#c4b5fd` | 없음 |
| RELEASE | `#22d3ee` | `#67e8f9` | 짧은 대시 |
| LINE_GUIDED | `#38bdf8` | `#7dd3fc` | 이중 실선 (센터 궤적과 구분) |
| SPEED_LIMIT | `#facc15` | `#fde047` | 없음. 내부에 `vmax` 텍스트 |
| DIRECTED / BIDIRECTED | `#e879f9` | `#f0abfc` | 없음. 방향 화살 오버레이 |
| COORDINATED_REPLANNING | `#c084fc` | `#d8b4fe` | 교차 `x` |
| ACTION | `#fbbf24` | `#fcd34d` | 없음. 코너 점 |

겹침: 교차 영역은 **우선순위가 높은 쪽 해치만** 그리고, 교차 외곽을 흰색 0.35 1px로 한 번 더 획습니다.

우선순위 (픽셀, 현장 배치 규칙과 동일):

```
forbidden/BLOCKED  >  corridor/complex/RELEASE/LINE_GUIDED  >  avoid/prefer 및 나머지 비용 존
```

`DIRECTED ∩ BIDIRECTED` 교차는 해치 대신 **노랑 경고 스트라이프** (`#facc15` α 0.35). 스펙상 금지.

현장 복도 폴리곤(인디고) vs VDA edge 리본(시안 α 0.10, 외곽 점선 `#38bdf8`): 색상 축을 다르게 해서 동시에 켜도 구분됩니다.

### 4.3 그래프 · 런타임

| 객체 | 그림 |
|------|------|
| node 미선택 | 채움 `#e2e8f0`, 원 5px, θ 바늘 10px |
| node 선택 | `--cyan` 글로우, 원 7px |
| edge | `#38bdf8` 1.25px 실선 + 끝 화살 |
| trajectory | `#7dd3fc` 1.75px, 제어점 4px 사각형 |
| ribbon | `#38bdf8` 채움 0.10, 좌우 점선 |
| portal | `#2dd4bf` 3px 선분 + 양끝 원 |
| rail | `#fbbf24` 2px 폴리라인, 화살은 headingMode에 따라 |
| waypoint | 기존 PNG, 호버 id |
| charger / station | 기존 PNG / station은 금색 링 1px 추가 |
| obstacle | `#f472b6` α 0.35 |
| 로봇 경로 | 로봇색 **점선** + 어두운 1px 외곽 (현 UI). 면적 칠 없음 |
| 선택 공통 | 흰색 1.5px + 바깥 4px glow `rgba(226,232,240,0.35)` |

Occupancy 오버레이는 기존: teal free, gold inflate, 어두운 blocked. α는 존보다 낮게 (0.25) 해서 존 해치가 위에 남습니다. 그리는 순서:

```
floor PNG → occupancy → 존 채움/해치 → 리본 → 엣지/궤적 → 포탈/레일 → 점 에셋 → 로봇/경로 → 선택 오버레이
```

레이어 토글로 중간을 건너뜁니다.

## 5. 인스펙터 필드 (선택별, 구현 수준)

공통 헤더: 종류 칩 + id (monospace) + `숨김` 체크(아웃라이너 눈과 동기).

단위: 캔버스 입력은 **px와 m를 나란히** (m = px × 0.05). θ는 rad + ° 슬라이더 (−π..π).

### 5.1 맵 루트 (상단 칩 클릭, 선택 없음과 구분)

`mapId`, `mapVersion`, `pixelCm`(읽기 5), 원점 x/y m, `yDown` 표시, occupancy 참조 파일명(읽기).

### 5.2 점

| 선택 | 필드 |
|------|------|
| waypoint | x, y, θ. 버튼 `VDA 노드로 승격` (VDA 모드에서만 enabled) |
| charger | x, y, θ. `스테이션으로 승격` |
| station | stationId, name, x, y, θ, kind(`charger`/`pick_drop`/`wait`/`other`), interactionNodeIds (노드 id 칩, 클릭으로 지정) |
| node | nodeId, x, y, θ, mapId, allowedDeviationXY, allowedDeviationTheta, actions[] 요약 (칩: startCharging / pick / drop / finePositioning). vehicleTypeIds 선택적 |
| robot (읽기) | id, status 뱃지, traffic 뱃지, x/y/θ. 운용일 때 `이 로봇 선택` `Cancel 주행` |

### 5.3 장애물

shape, x, y, size (10–80, 숫자+슬라이더), θ (원 숨김). 삭제.

### 5.4 현장 존

공통: id, name, 정점 개수, 면적 m², 정점 표 (접힘, x/y 편집).

| kind | 추가 |
|------|------|
| forbidden | 없음. `occupancy lethal` 힌트 |
| prefer | cost_scale 슬라이더 0.1–0.9 기본 0.4 |
| avoid | cost_scale 1.2–8 기본 3 |
| corridor | capacity 1\|2, portals 목록, rails 목록, 폭 측정값(측정 도구 연동) |
| complex | capacity 기본 1, portals, releaseLossBehavior `STOP`/`CONTINUE`/`EVACUATE` |

### 5.5 VDA 존

공통: zoneId, name, zoneType(읽기=도구에서 고정, 셀렉트로 변경 가능), 정점, 면적.

| zoneType | 추가 |
|----------|------|
| BLOCKED | 없음 |
| RELEASE | portals, (플릿) capacity 표시는 현장 복도와 동일 필드명으로 둘지 합의 |
| LINE_GUIDED | 연결 엣지/레일 id |
| SPEED_LIMIT | maximumSpeed m/s |
| PRIORITY | priorityFactor 0..1 |
| PENALTY | penaltyFactor 0..1 |
| DIRECTED | direction rad, limitation `SOFT`/`RESTRICTED`/`STRICT` |
| BIDIRECTED | limitation 동일 |
| COORDINATED_REPLANNING | 없음 |
| ACTION | 진입/통과/이탈 액션 타입 문자열 |

### 5.6 엣지

edgeId, startNodeId, endNodeId (링크 클릭=선택 점프), maximumSpeed, length(읽기=궤적 길이), trajectory 점 개수, corridor: leftWidth, rightWidth (m), corridorReferencePoint `KINEMATIC_CENTER`/`CONTOUR`, releaseRequired, releaseLossBehavior `STOP`/`RETURN`, vehicleTypeIds.

### 5.7 포탈 / 레일

Portal: id, 선분 양끝, waitPose x/y/θ 선택.

Rail: id, 점 개수, headingMode `path_tangent`/`fixed_theta`.

### 5.8 다중 선택

`n개 선택` · 종류 집합 나열 · `삭제`. 같은 종류만이면 x/y 오프셋 입력 하나.

삭제 확인: 점·장애물은 즉시(현 UI). 존·엣지는 인스펙터 `삭제` 한 번 더 또는 Delete 후 상태바 undo 힌트 (`Ctrl+Z`). 모달 남발 금지.

## 8. HTML/CSS/TS 구현 제약 (레이아웃 추측 방지)

권장 마크 골격 (프레임워크 없이 `index.html`):

```
body[data-mode="ops|site|vda"][data-tool="select"]
  header#topbar
  div.shell
    nav#rail
      button[data-rail=common|ops|site|vda][data-tool][aria-pressed]
    main#viewport
      canvas#map
      div.hud-layers / hud-legend / hud-zoom / hud-minimap
    aside.dock-right
      section#outliner
      section#inspector
  footer#statusbar
```

- 도구 상태는 `body.dataset.tool`, 모드는 `body.dataset.mode`. CSS가 레일·액센트를 담당하고, TS는 히트테스트·월드 카메라만.
- 캔버스 리사이즈: `ResizeObserver` on `#viewport`.
- 카메라: `{ x, y, scale }` 한 객체. 렌더 `setTransform`.
- 레일 아이콘 SVG는 현 툴바와 같은 24 viewBox inline.
- 인스펙터 폼은 `innerHTML` 통째 교체보다 `<template id="insp-node">` 복제가 안전합니다.
- 폰트: 현 `-- :root` (`Segoe UI`, `IBM Plex Sans`, `Noto Sans KR`).

하지 말 것: occupancy 브러시, 고정 720×560 CSS 맵, 저작/명령을 한 툴바에 재혼합, 존 솔리드 불투명 칠.

## 합의 요청

- 현장 존(`forbidden`/`prefer`/`avoid`/`corridor`/`complex`)과 VDA `zoneType` 원형(BLOCKED, RELEASE, …)을 **별도 객체 두 벌**로 둘지, 인스펙터 kind 셀렉트 하나로 합치고 모드만 라벨을 바꿀지.
- `corridor` 폴리곤(용량·포탈·레일)과 `edge.corridor` 리본을 동시에 켜 둔 채 편집하는 것이 기본인지, 아니면 현장 모드에서 리본 레이어를 강제 off할지.
- 운용 모드에서 존/노드 **드래그 이동을 완전 잠글지**, 선택은 되고 이동만 막을지.
- 스테이션 도구 키 `C`가 현장에서 충전과 겹칩니다. VDA에서 `C`=스테이션을 유지할지, 스테이션을 `S`로 옮길지 (현재 `S`는 비어 있음. 스냅은 `;`).
- 아웃라이너 높이 240px / 우측 340px가 1280×800 기준입니다. 접힘 기본값을 열어 둘지, 작은 창에서 기본 접을지.
- 연속 배치(도구 유지) vs 하나 놓고 선택 도구로 복귀. 이 문서는 **연속 배치**입니다.
- 실행 취소 스택을 클라이언트 로컬만으로 둘지 (새로고침 시 소실).
- ACTION 존 P2를 레일에 이미 넣을지, `…` 더보기로 숨길지.
