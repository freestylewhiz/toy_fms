# Atlas Studio — 전체 UI 재설계

2026-09-14. 기존 화면의 색상 보정 수준을 넘어 전체 레이아웃과 작업 동선을 교체했다.

## 화면 구조

- 상단: 제품, 현재 맵, 운용/현장 배치/VDA 모드, 패널 표시, 연결 상태.
- 왼쪽: 도면 썸네일이 있는 맵 라이브러리, 리소스 검색, 스크롤 가능한 리소스 목록.
- 중앙 상단: 모드 설명과 가로형 배치 도구. 기본 진입은 현장 배치.
- 중앙: 밝은 점 격자 작업 영역, 맵 컨텍스트, 조작 안내, 확대/축소/화면 맞춤. 편집 중 하단 확인/취소.
- 오른쪽: 속성/레이어/로봇 탭. 운용 진입 시 로봇 탭, 편집 모드 진입 시 속성 탭.
- 작은 화면: 상세 패널은 접을 수 있는 오버레이, 모바일에서는 맵 선택 드롭다운 사용.

## 동작 및 보호

리소스 검색은 목록 갱신 이후에도 유지된다. 목록 선택은 속성 탭을 연다. 모드/패널/화면 크기 변화는 ResizeObserver로 캔버스 해상도를 갱신한다. 미저장 편집 중 맵 전환에는 편집 취소 확인을 추가했다.

맵 전환은 여전히 yard 편집 및 1st_floor 미리보기 범위다. 다른 좌표계에 yard 로봇이 잘못 표시되지 않도록 미리보기에서는 로봇도 숨긴다. gRPC, Colyseus, SQLite 서버 저장 구조는 변경하지 않았다.

## 코드

- `web-client/src/styles.css`: 전체 스타일 교체. 기존 다크 테마 덮어쓰기 규칙 제거.
- `web-client/src/workspace.ts`: 기존 편집 컨트롤을 새 패널 구조에 배치하고 탐색/탭/검색 이벤트 연결.
- `web-client/src/main.ts`: 편집 동작, 맵 보호, 캔버스 크기와 보기 제어 연결.
- `web-client/index.html`: 브랜드 및 빈 선택 상태 재설계.
- `scripts/check_workspace.ts`: 서버 실행 상태에서 검색, 선택, 레이어, 맵 전환, 읽기 전용 보호, 모드별 캔버스 크기, 패널, 반응형, 편집 취소 검증. DB 변경 없이 실행.

검증 명령: `bun run scripts/check_workspace.ts`.
실행 주소: `http://localhost:5174`.
웹 서버는 시작할 때 번들을 빌드하므로, 실행 중 소스 수정 시 번들을 다시 빌드해야 한다.
