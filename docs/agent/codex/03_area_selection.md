# 영역 선택

2026-09-14

- 공통 보기 도구에 영역 선택(B)을 추가했다.
- 캔버스에서 사각형을 드래그하면 보이는 레이어의 리소스를 선택한다. 로봇은 제외한다.
- 점 형태 리소스와 장애물은 기준점, 폴리곤·선은 전체 형상이 사각형 안에 있을 때 선택한다. 드래그 방향은 무관하다.
- Shift 드래그는 기존 선택에 추가한다. Esc 또는 선택 해제로 해제한다.
- 선택된 형상을 파란 경계로 표시한다. 속성 패널에서 종류별 개수, 선택 항목 화면 맞춤, 선택 해제, 삭제를 제공한다.
- 삭제는 확인 후 기존 개별 삭제 메시지를 전송한다. 서버의 원자적 일괄 처리나 실행 취소는 제공하지 않으며 서버 오류는 기존 상태 메시지로 표시된다.
- 단일 편집/도구/맵 전환 시 다중 선택은 해제한다. 서버 통신 및 SQLite 구조는 변경하지 않았다.

검증: 영역 포함 판정 단위 테스트 통과. 실제 브라우저에서 31개 선택, 화면 맞춤, 삭제 확인 취소, 선택 해제를 확인했다. 테스트 중 실제 삭제는 수행하지 않았다.

확장 후보: 일괄 이동, 복제, 같은 종류의 속성 일괄 변경, 정렬과 간격 배치. 이동과 복제는 노드 연결 및 구역 종속 항목의 참조 처리, 경계/점유 검증이 필요하다.
