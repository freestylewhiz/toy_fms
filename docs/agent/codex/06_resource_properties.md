# 리소스 속성 편집 및 UI 개편 — 2026-09-15

## 동작

- prefer 등 존을 클릭해 편집 세션에 들어간 상태에서도 Delete로 리소스 삭제.
  삭제 버튼도 편집 세션·정점 선택·미리보기를 해제해 잔상과 재생성을 방지한다.
- 모든 리소스 생성 초안에 이름과 UUID 기반 고유 ID를 부여한다. 기존 ID 유지.
  obstacle / portal / rail 이름 컬럼은 기존 SQLite 데이터에 추가하며 데이터를 보존한다.
- pose / zone / edge / portal / rail 속성 입력을 초안으로 통일하고 저장·취소 제공.
  서버 editorAck 확인 후 완료 처리하고 오류·단절 시 초안을 유지한다.
- 이름·θ·위치·반지름 등 종류별 속성과 중심·면적·좌표·연결 정보를 표시한다.
  화면 θ는 도, 저장 θ는 라디안. 존·레일 회전 시 좌표도 회전시킨다.
- 전체 snapshot 메타데이터를 보존해 이름 변경 시 노드 액션, 스테이션 연결,
  엣지 경로·회랑, 포털 대기 위치, 존 방향 규칙 등이 지워지지 않게 했다.
- 속성 변경은 로봇 텔레메트리로 덮어쓰지 않는다. 목록 DOM도 내용 변경 시만 교체.
- 장애물 속성 저장에도 기존 로봇 배치 허용 질의를 적용한다.
- 다크 그래파이트/청록색 UI, 고정 속성 액션, 도형 정보 스크롤, 반응형 패널.
  편집 바와 화면 맞춤 버튼의 겹침 및 사각형·삼각형 렌더링 함수 인자 오류 수정.

## 후속: 삭제 확인과 Atlas Studio 레이아웃

- `confirmation.ts`: 네이티브 dialog로 이름·종류·ID 및 일괄 삭제 건수를 표시.
  확인 전에는 전송하지 않으며 취소/Esc는 초안을 보존한다. 최초 포커스는 취소.
  중복 호출은 거절하며 대기 중 키보드 입력이 편집기로 전달되지 않는다.

  순수 마키 선택에서도 Delete 키가 작동하도록 수정했다.
- `workspace.ts`, `icons.ts`, `overview.ts`: 탐색/필터, 도형 미리보기, 회전 나침반,
  네이비 청사진·라임 포인트, 미니맵 이동, Ctrl/⌘K 도구 팔레트, ShiftF 집중 모드.
