# 맵 에디터와 작업 공간

## 화면과 모드

현재 UI는 탐색기·Canvas 지도·속성/레이어/로봇 패널로 구성된다.
yard와 large_lab은 편집·운용 맵이고 1st_floor는 읽기 전용 미리보기다.
large_lab의 규모와 렌더링 범위는 [대형 맵](../../concept/current/large-test-map.md)을 따른다.

| 모드 | 역할 |
| --- | --- |
| 운용 | 로봇 선택·이동·도킹·취소 |
| 현장 배치 | 웨이포인트·충전소·장애물·현장 존 |
| VDA 배치 | 노드·엣지·스테이션·존·포털·레일 편집 |

VDA 배치라는 이름은 실제 VDA 주문 전송이나 그래프 주행 구현을 뜻하지 않는다.

탐색기는 이름/ID 검색과 종류 필터를 제공한다. Ctrl/⌘ K는 도구 검색,
Shift F는 집중 모드, /는 검색 진입이다. 휠로 줌, 스페이스 또는 우클릭 드래그로 팬,
0으로 전체 맵 맞춤을 한다. 청사진/원본 도면 표시와 미니맵 이동을 제공한다.

## 편집 정책

배치·속성 수정은 초안에서 수행하고 저장 또는 취소한다.
서버 확인 후 저장 완료로 처리하며 실시간 로봇 패치가 입력 초안을 덮어쓰지 않는다.
이름을 바꾸어도 ID는 유지한다. 좌표는 px, 각도 저장은 rad이고 UI에서는 도 단위도 표시한다.

존은 단순 폴리곤이다. 자기 교차를 거부하며 정점·중점으로 형태를 수정한다.
존 중심 이동·회전은 전체 정점에 적용한다. Backspace는 정점을 삭제하고 최소 3개를 유지한다.
Delete는 기존 리소스 삭제 확인창을 열고 Esc는 취소한다.
삭제 취소 시 기존 선택·입력 초안을 유지한다.

영역 선택(B)은 보이는 리소스를 선택하고 로봇은 제외한다.
점 리소스는 기준점, 폴리곤·선은 전체 형상이 사각형 안에 있을 때 선택한다.
Shift 드래그로 추가 선택한다. 다중 삭제는 확인 후 개별 삭제 메시지를 전송하며 원자적 일괄 처리가 아니다.

## 속성과 실행 의미

비용 계수·존 용량·최대 속도, 노드 허용 오차, 엣지 회랑 폭,
스테이션 용도, 포털·레일 연결 구역을 편집할 수 있다.
실제 주행에 반영되는 존은 [FMS 트래픽](../../fms/current/traffic.md)을 따른다.
edge 회랑 폭은 속성이며 별도 편집 폴리곤이 아니다.

편집 리소스는 editor.sqlite에 저장한다. 로봇의 최근 위치·운영 설정은 별도의 runtime.sqlite에서 관리한다.
