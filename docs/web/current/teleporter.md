# 텔레포터 웹 편집기

상태: 기본 구현 및 2026-09-17 Yard 현장 배치 수정. 사용자 검토는 PILOT-14에서 관리한다.

## 현재 동작

- Scene 및 VDA 보조 도구에서 `teleporter`를 선택하면 전용 양끝점 배치 흐름이 시작된다.
- 현재 맵에 A 끝점을 배치한 뒤 속성 패널에서 연결할 편집 가능 맵을 선택한다.
- 연결할 층을 선택하면 즉시 해당 맵으로 전환하고, 같은 텔레포터를 선택한 상태로 B 끝점 편집을 시작한다.
- 전환 후에도 미저장 초안과 A 설정을 유지한다. 현재 맵의 끝점 중심을 드래그해 위치를 옮길 수 있으며 clearing point도 같은 이동량으로 따라간다.
- 끝점마다 40×40 px 기본 점유 사각형, 진입 방향, 출구 방향, clearing point가 생성된다.
- 점유 영역은 지도에서 정점을 드래그하거나 패널의 정점별 좌표 입력으로 수정한다.
- clearing point는 지도에서 직접 지정하거나 X/Y 입력으로 수정한다. 점유 영역 안에 있으면 저장하지 않는다.
- 지도에서 편집한 이탈 지점·점유 정점은 속성 패널에도 반영한다. 다른 맵에 있는 끝점의 이탈 지점은 해당 맵으로 전환한 뒤 지정한다.
- 저장된 텔레포터의 끝점 속성을 바꾸면 수정 초안을 만든다. 저장 전까지 서버 정본을 변경하지 않으며 취소로 복원한다.
- 저장된 텔레포터를 지도에서 클릭해도 즉시 수정 초안으로 전환한다. 현재 맵의 끝점 중심을 바로 드래그해 위치를 옮긴 뒤 저장할 수 있다.
- 일반 맵 전환은 끝점 재배치를 시작하지 않는다. 텔레포터 속성의 연결 층 선택은 예외로, 선택 즉시 해당 끝점의 배치·재배치 모드로 전환한다.
- 저장은 `teleporterUpsert`와 `requestId`, `expectedRevision`을 사용하며 ACK 전까지 초안을 유지한다.
- 삭제는 `teleporterDelete` ACK 후에만 목록에서 제거한다.
- 로봇 운용 화면에서 텔레포터 끝점을 선택하면 `commandRobot`의 `kind: "teleporter"`, `targetId`, `endpointId`로 명령한다.

## 서버 스냅샷 계약

서버는 `FloorState.teleportersJson`에 공용 텔레포터 정의를 JSON 배열로 게시한다. 웹은 각 맵 room에서 동일한 definition을 읽고 현재 맵에 속한 끝점만 그린다.

끝점은 `mapId`, `position`, `entryTheta`, `exitTheta`, `occupancyPolygon`, `clearingPoint`를 사용한다. 점유 상태와 대기 사유는 서버가 게시한 끝점 상태를 사용한다.

## 검증

`bun run check:teleporter:web`는 저장소 기준 경로에서 격리된 두 맵 FMS와 공용 `TELEPORTER_SQLITE_PATH`를 임시 디렉터리에 기동한다. `E2E_PORT_OFFSET`로 포트를 바꿀 수 있으며, 종료 시 모든 프로세스를 정리한다. 검사는 배치, 취소, 저장, reload, 양쪽 snapshot, endpoint ID 보존, 저장된 리소스 재편집 취소, 삭제를 포함한다.

검증 결과: 2026-09-16 `PASS browser placement, map rejoin, persistence, cancel and delete`. 웹 단위 테스트 8개와 웹 번들 검사를 통과했다.

잘못된 맵의 끝점 수정 및 맵 전환 시 배치 단계 초기화를 보완했다. 실제 Yard 화면에서 초안 배치·이탈점 클릭·
폴리곤 정점 드래그를 확인했고, 격리 Chromium 검사에 현장 배치와 저장 리소스 재편집 회귀를 추가했다.

Yard 복귀 후 B 끝점 보존·연결 층 선택·재배치 도구·전체 취소를 확인했다. 운영 DB에는 테스트 초안을 저장하지 않았다.

Large Lab에서 보이는 텔레포터도 선택 후 끝점 이동·속성 편집·저장이 가능하다.

2026-09-17 추가 수정: Large Lab의 끝점이 보이지 않던 직접 원인은 웹이 서버 프로세스가 시작할 때 정해진
기본 맵 ID를 사용해 다른 맵의 끝점을 필터링한 것이었다. 웹의 현재 선택 맵을 렌더링·선택의 기준으로
사용하도록 고쳤다. 끝점 원·방향·라벨과 선택 반경도 확대·축소에서 화면 기준으로 보정하며, 저장된 점유
폴리곤의 실제 크기는 변경하지 않는다. 저장 ACK 뒤에는 선택 도구로 돌아가므로 저장된 끝점을 다시 클릭하면
새 텔레포터 초안이 아니라 수정 초안을 연다. 격리 Chromium E2E에서 Large Lab 마커 픽셀 렌더, 직접
드래그와 clearing point 동반 이동, 저장·재로딩 후 재선택을 확인했다.
