# 로봇 이벤트 콘솔

2026-09-22 PLAN-15 / WEB-7 / SRV-10 / ROBOT-8. 사용자 구현 승인에 따라
기존 블랙박스 기록을 로봇 단위로 조회하는 콘솔을 추가했다. 통합 감사 메뉴와
전체 stdout/stderr 수집은 이번 범위에 포함하지 않는다.

## 화면

운영 화면의 주행 일시정지 영역에서 **이벤트 콘솔**을 연다. 로봇, 기간(15분·1시간·24시간),
종류, 수준을 선택하고 명령·계획·연결·오류 기록을 시간순으로 확인한다.
2026-09-23부터 목록은 **시각 + payload 기반 자연어 설명**을 표시한다. 명령 종류,
좌표·방향, 전체 commandId와 목표 리소스 이름을 조합하고, 분류·수준·출처는 보조 정보로 둔다.
이벤트를 선택하면 JSON 원문과 operation/command/request ID를 확인하고 복사하거나
기존 관련 trace로 이동한다. HTTP 환경에서는 Clipboard API가 없을 때 복사 대체 경로를 사용한다.

실시간 따라가기는 약 1초 간격으로 새 기록을 조회한다. 화면 따라가기를 끄면 진행 중인
라이브 조회 응답도 화면에 적용하지 않는다. 이 조작은 로봇 주행 상태를 바꾸지 않는다.
**이전 이벤트 더 보기**는 화면 정지 상태에서도 가능하다. 행은 최대 500개를 유지하며
과거 조회와 실시간 조회의 보관 방향을 구분한다. 로봇·맵·필터 변경 시 과거 요청 응답을
무시하고, 콘솔 닫기·리플레이 전환 시 라이브 조회를 중단한다.

적용 상태, 조회 중·timeout·연결 끊김, 기록 공백과 조회 범위 잘림을 구분해 표시한다.
반복 pose·heartbeat는 기본 숨김이다. 위치 지정 명령·ACK·실패 같은 의미 있는 이벤트는
숨기지 않는다. 오류 수준이 없는 기존 기록은 error 종류이면 error, 그 외에는 info로 해석한다.

## 기록과 조회 계약

로봇의 명령 수신·실행·완료·거절, 계획 요청·완료·폐기·실패, 연결·오류를 기존 NDJSON에
구조화해 기록한다. 로봇·세션·운용·명령·요청 ID를 유지하며 운용 ID 없는 오류도 조회한다.
로깅 실패가 주행 명령이나 일시정지 ACK를 차단하지 않는다. 기존 민감 필드 마스킹을 유지한다.
일시정지 요청의 운용 ID와 계속 수행 중인 이동 명령의 원래 운용 ID를 구분한다.

웹은 `robot_events_query`를 보내고 `robot_events_result`를 받는다.
요청은 robotId, fromMs/toMs, levels/categories, limit, cursor를 지원한다.
페이지 크기는 최대 500개다. 과거 조회 커서는 asOf·로봇·맵·시간·필터와 파일별 읽기 위치를
고정해 중간에 기록이 추가되어도 과거 페이지가 밀리지 않게 한다. 다른 조회 조건에 커서를
재사용하면 거부한다. 조건에 맞는 행이 없는 구간에서도 커서로 더 오래된 기록에 접근한다.

대상 로봇 및 FMS의 인덱스를 파일별 제한된 창으로 읽는다. 기준 창은 256 KiB이며
쿼리별 인덱스 읽기 예산은 약 4 MiB, 보관하는 참조는 최대 32,000개다.
경계 줄 해석에 필요한 소량의 겹침 읽기는 별도로 수행한다. 전체 맵 체크포인트는 콘솔에서
제외하고, NDJSON 본문은 인덱스가 가리키는 필요한 이벤트만 읽는다.
더 읽을 구간은 nextCursor와 truncated로 표시하며 recorder gap은 별도 gap으로 전달한다.
기록 보존 기간과 원본 파일 관리는 [블랙박스 기록](../../fms/current/blackbox.md)을 따른다.

## 2026-09-23 공통 코드와 자연어 표시

코드·표시명은 [공통 카탈로그](../../concept/current/code-catalogs.md), 조합 규칙은
[이벤트 formatter](../../../shared/eventDisplay.ts)에서 관리한다. 예를 들어 이동 명령은
`robot-1 이동 명령을 받음 x:320 y:520 theta:0 · 목표 포장 출구 · commandId=...`로 표시한다.
실제 목록은 commandId를 생략하지 않는다.

목표 이름은 명령 시점의 서버 리소스에서 복사한다. 이후 이름 변경·삭제에도 과거 이름을
유지하며, 이름을 기록하지 않은 기존 이벤트는 원래 ID를 표시한다. 알 수 없는 코드는
원문으로 남기고 상세 JSON은 보존한다. 이름은 HTML로 해석하지 않고 텍스트로 표시한다.

격리된 두 로봇·Chromium 검사에서 특수문자 이름, 명령 후 이름 변경, 자연어 목록,
JSON 상세·복사·trace·조회·일시정지 회귀를 통과했다. 전체 자동 검사 300개 통과.
근거: `/tmp/fms-pause-console-Oja9Ti/result.json`, 페이지 오류 0건. 운영 배포는 하지 않았다.


## 2026-09-23 자연어 기본 보기 보완·웹 반영

사용자 재검수에서 이벤트 콘솔이 데이터 형식으로 보인다는 지적을 확인했다. 운영 웹은
formatter가 없는 이전 app.js를 제공 중이었고, 소스에도 이벤트 선택·관련 trace 조회 시
JSON을 바로 펼치는 경로가 남아 있었다.

목록·선택 이벤트 설명·관련 기록은 공통 formatter로 자연어를 표시한다. 코드형 부가 ID의
중복 나열을 제거하고 긴 설명은 줄바꿈한다. 원문은 기본적으로 접힌 **JSON 원문 보기** 안에서만
표시하며 복사 버튼도 이 뷰에 둔다. 선택 이벤트·로봇·필터가 바뀌면 JSON 뷰를 닫고
이전 관련 기록을 비운다. 블랙박스의 관련 기록도 자연어와 접힌 JSON 뷰를 분리했다.
구역 상태 갱신의 STOP 등은 구역 상태 카탈로그의 표시명을 사용한다.

관련 자동 검사 23개와 격리 서버·로봇 2대·Chromium 검사 12개 항목을 통과했다.
격리 검증: `/tmp/fms-pause-console-nT7QDI/result.json` 및 `event-console-natural.png`.
현재 제공 경로의 웹 app.js 번들을 교체했으며 웹·FMS·로봇 프로세스는 재기동하지 않았다.
기존 서비스에서도 조회만 수행해 자연어 목록, 기본 JSON 숨김, 명시적 JSON 열기를 확인했다.
페이지 오류 0건. 근거: `/tmp/fms-natural-console-live.json`, `/tmp/fms-natural-console-live.png`.
기존 브라우저 탭에는 새로고침이 필요하다. 서버·로봇의 이전 코드 리팩터링 배포는 별도다.
