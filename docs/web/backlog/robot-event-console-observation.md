# 로봇 이벤트 콘솔 프리셋과 관찰 화면 제안

2026-09-22 사용자 요청에 따라 PLAN 카드에 기록하는 기획이다. 구현 승인이 아니며
현재 [이벤트 콘솔](../current/robot-event-console.md)의 실행 동작을 바꾸지 않는다.

## 목적별 프리셋

운용·FMS 프로토콜·주행/트래픽·오류 목적을 복수 선택해 함께 관찰한다.
프리셋은 내부 category 이름을 그대로 노출하는 수준보다 사용자가 찾는 사건을 기준으로 정의한다.
반복 보고 숨김, 동일 메시지 묶기를 검토하되 상태 변화·오류·종결 결과는 보존한다.
숨긴 원본과 집계 횟수·시간 범위를 확인할 수 있어야 하며 command ID를 중심으로 trace를 연결한다.

## 관찰 화면

- 화면 하단의 높이 조절 가능한 콘솔과 최대화.
- 지도에서 선택한 로봇 따라가기와 선택 상태 고정.
- 사건 목록과 원문 상세를 나눈 화면.
- 장시간 관찰에서 스크롤·선택·필터·상태 표시가 갱신 때문에 흔들리지 않는 동작.

## 후속 합의

프리셋별 포함/제외 종류, 중복 묶기 키·기간, 고정 상태와 로봇 선택의 우선순위,
기록량 상한·펼치기·원문 접근을 기획 검토한다. 블랙박스 v2 수정 구현과 별도 작업이다.


2026-09-23: 별도 사용자 승인으로 공통 코드 카탈로그와 payload 기반 자연어 이벤트 설명을
구현했다. [현재 동작](../current/robot-event-console.md)을 참조한다. 이 문서의 목적별 프리셋과
관찰 UI 개선 전체를 승인·완료한 것은 아니다.
