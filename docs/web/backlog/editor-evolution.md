# 편집과 모니터링 확장

상태: 논의 후보. 이미 구현된 맵 미리보기·속성 저장·영역 선택·삭제 확인은 재개발 과제로 남기지 않는다.

## 멀티맵·그래프 편집

읽기 전용 맵을 편집·운용 맵으로 확장하려면 서버의 mapId 분리와 계약을 먼저 합의한다.
노드/엣지 연결, 스테이션과 충전소 관계, 그래프 버전 표시를 결정한다.
관련: [FMS 그래프 논의](../../fms/backlog/maps-and-graph.md).

## 일괄 편집

일괄 이동·복제·공통 속성 수정·정렬·실행 취소가 필요한지 결정한다.
노드 연결과 존 종속 리소스의 참조 보존, 경계·점유 검증, 부분 실패 및 원자성 처리가 선행 조건이다.
현재 다중 삭제를 트랜잭션으로 오해하지 않도록 UX를 검토한다.

## 검증과 운영 정보

Canvas 좌표 클릭에 의존하는 검사의 안정화를 위해 월드 좌표 도우미 또는 테스트 진입점을 검토한다.
영구 명령 이력·인증된 감사 정보 UI는 서버 범위가 정해진 뒤 논의한다.
이 항목들은 사용 필요성을 확인한 뒤에만 todo로 옮긴다.
