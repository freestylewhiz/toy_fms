# 트래픽 컨트롤 v2 — 자유 공간의 시공간 양보

**구현하지 않는다.** 검토와 우선순위 문서다.

사용자 정의 존(`corridor` / `complex` / `forbidden` / `avoid` / `prefer`)은
[`../user_defined_traffic_zone/`](../user_defined_traffic_zone/README.md) 가 담당한다.

v2 가 묻는 것은 그것만 빼면 남는 질문이다.

> 아무 설정도 없는 칸에서, 로봇이 A→B 를 스스로 가면서
> 서로의 경로를 방해하지 않고, 폭이 되면 교행하고,
> 큰 우회 대신 잠깐 기다리거나, 필요할 때만 FMS가 “일시 선호” 힌트를 주려면
> **무슨 방법론을 어떤 순서로** 쓰는가?

---

## 한 줄

> 자유 공간에서는 상대 5초 경로를 벽으로 만들지 않는다.
> **같은 시각에 같은 칸을 쓰지 않으면** 기하 경로는 겹쳐도 된다.
> 충돌이 예상되면 먼저 감속·대기, 폭이 되면 짧은 교행, 그래도 안 되면 작은 우회.
> 큰 A* 우회와 복도 후진은 마지막이다.

v1 은 로컬 플랜을 **지금 있는 장애물**로 넣어 3번(우회)부터 시작했다. 그게 스무스를 죽였다.

---

## v0 / v1 과의 자리

| | v0 | v1 | v2 (안) |
|---|---|---|---|
| 전제 | 로봇은 경로를 이탈한다 (F1) | 짧은 로컬 플랜을 공유 | 동일 + **시간은 공유** |
| 평시 | 회랑 임대 (전 맵 신호등) | 플랜을 공간 벽으로 A* | 플랜을 시공간 예약. 경로는 유지 |
| 존 | 없음 | 없음 | 사용자 존은 **다른 모듈** |
| FMS | 좌표 없음 | 교착 때만 REROUTE/VACATE | 분쟁 때 delay 중재, 선택적 힌트 폴리라인 |
| 안전 | I1∧I2 증명 | 예측 occupancy | 단기: 시공간 disjoint. 하드 안전은 근접 정지 + (선택) 짧은 회랑 |

v2 는 v0 를 버리지 않는다. **사용자 존과, 자유 공간에서 증명이 필요할 때** 영역 임대를 국소적으로 쓸 수 있다.
전 맵에 신호등을 켜지 않는 것이 차이이다.
