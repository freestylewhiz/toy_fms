# 문제 — 자유 공간에서 겹치지 않으면서 스무스하게

---

## 1. 목표가 두 개가 아니다

자주 섞이는 문장:

- “경로가 겹치면 안 된다”
- “우회는 너무 크면 안 된다”
- “폭이 되면 교행해야 한다”
- “상대 경로를 알면 기다릴 수도 있다”

한 문장으로 합치면:

> **같은 (공간, 시각) 쌍을 두 몸이 쓰지 않는다.**
> 그 제약을 만족하는 궤적 중, **기하 경로를 덜 바꾸고 급정거를 덜 하는** 쪽을 고른다.

“경로 선분이 맵에서 교차하면 실패”가 아니다.
교차로에서 한 대가 1.5초 늦게 지나도 선은 교차하지만 몸은 안 겹친다.

v1 버그(설계)는 이 구별을 안 한 것이다. 5초 폴리라인을 전부 현재 벽으로 넣으면
교차는 항상 “큰 우회”로 풀린다.

---

## 2. 자유 공간이 아닌 것 — 이 문서 밖

다음이 보이면 사용자 존이지 v2 가 아니다.

| 현상 | 존 |
|------|----|
| 폭이 두 대를 못 넣음 | `corridor` capacity 1 |
| 넣으면 아슬, 지정 줄로만 | `corridor` + rail |
| 넓지만 한 대만 | `complex` |
| 들어가면 안 됨 | `forbidden` |
| 최단이 아닌 운영 통로 | `prefer` / `avoid` |

알고리즘이 복도를 추정해 후진하는 것은 **존 미배치의 응급처치**다.
기본 전략으로 올리지 않는다.

---

## 3. 왜 방법 하나가 부족한가

| 가족 | 잘함 | 못함 |
|------|------|------|
| 공간 A* 우회 (v1) | 막힌 앞을 돌아감 | 스무스·대기·교행. 복도에서 폭발 |
| 속도만 조절 (Kant–Zucker, 조정도표) | 경로 유지, 스무스 | 로봇이 경로를 이탈하면(F1) 예약이 거짓. 폭이 있는데도 줄 서서 기다림 |
| ORCA/RVO | 로컬 교행이 부드러움 | 복도 교착·전역 살아남기 없음. 의도 공유 없으면 춤 |
| 전 맵 회랑 임대 (v0) | 충돌 증명 | 평시 과도한 정지, 자율 우회 억제 |
| 전역 MAPF (CBS 등) | 최적에 가까움 | 실시간·경로 이탈·사람 장애에 약함 |

그래서 **스택**이 필요하다. 우선순위는 [`03_policy.md`](./03_policy.md).

---

## 4. F1 을 자유 공간에서 어떻게 다루나

v0: 로봇은 보고한 경로를 지킬 보장이 없다 → 권한은 영역이어야 한다.

v2 자유 공간의 타협:

1. **단기(약 `LOOKAHEAD_S`) 시공간만** 믿는다. 5초 뒤 전역 경로는 안 믿는다.
2. 몸이 예약 밖으로 나가면 그 로봇이 감속·재예약한다 (I2 의 짧은 버전).
3. 사람이 나타나 경로를 이탈하면, 이탈한 로봇의 새 로컬 플랜이 예약을 갈아끼운다.
4. 하드 충돌 방지의 마지막 줄은 **근접 정지**(시뮬: 피어 바디 디스크)이지, 5분짜리 MAPF 가 아니다.

즉 자유 공간의 안전은 “전 맵 I1”이 아니라 **가까운 미래 예약 + 바디 마진**이다.
증명이 꼭 필요한 통로는 사용자 `corridor` 로 올린다.

---

## 5. 스무스를 해치는 것 (현재 코드)

구현 대상이 아니지만, v2 가 피하려는 실패 모드다.

1. 그리드 A* + 꺾인 코너를 교통 회피마다 다시 탐.
2. 상대 플랜을 원  discretisation 으로 두꺼운 벽 만들기.
3. 막힐 때마다 전역 재계획 (경로 점프).
4. 둘 다 동시에 우회 (대칭 양보).
5. 목표 칸에 상대가 있으면 스냅 후 idle.

v2 는 1~4를 **시간 축으로 먼저** 풀도록 바꾼다.
