# 채택 스택 — 무엇을 어떤 순서로

구현 없음. 자유 공간(사용자 존 밖)에서 bg_fms 가 가져갈 **우선순위**.

---

## 0. 한 줄 규칙

상대 로컬 플랜과 내 로컬 플랜이 시공간에서 겹칠 것 같으면:

```
1. 감속 · 제자리 대기     (기하 경로 유지)
2. 짧은 교행 횡변위       (ORCA식, 경로를 버리지 않음)
3. 작은 우회              (대기보다 분명히 쌀 때만)
4. FMS delay 중재         (둘 다 1~3을 못 고를 때 sticky 승자)
5. FMS 일시 prefer 힌트   (우회가 필요하지만 A*가 과하게 돌 때)
6. 근접 정지              (무엇이든 실패. 충돌만 막음)
```

**하지 않는 것**

- 5초 폴리라인 전체를 현재 벽으로 넣고 전역 A*.
- 복도 한가운데 VACATE를 기본값으로.
- 이름 해시로 매 초 승자 교체.

사용자 `corridor` / `complex` 에 들어가면 이 스택을 **건너뛰고** 토큰 문법으로 간다.

---

## 1. 정보

각 로봇 → FMS → 같은 맵 로봇:

```
LocalPlan = { points[k], t[k] }   // k는 LOOKAHEAD_S 동안, Δt ≈ TICK
```

v1 의 `points` 에 **시각**을 얹는다. 속도가 일정하면 `t[k] = k * ds / v` 로 채워도 된다.

FMS는 좌표를 만들지 않는다. 미러하고, 겹침(`spacetime overlap`)만 본다.

로봇 로컬 occupancy:

- 상대 **몸** → 하드 원 (지금처럼). 항상 피함.
- 상대 **플랜** → 시각이 가까운 구간만 비용↑ / 속도 제약. 먼 미래는 거의 무시.

---

## 2. 층별 동작

### L1 — 대기 (기본)

내 경로 `π` 와 상대 시공간 예약이 겹치면, `π` 는 유지하고 `v` 만 줄이거나 정지.

짧은 조정도표: 두 곡선 `s_a(t), s_b(t)` 가 충돌 블록을 지나는지.
통과하는 대는 속도 유지, 양보하는 대는 블록 앞에서 `s` 고정.

**누가 양보하는가 (sticky)**

1. 이미 충돌 구간을 더 많이 지나온 쪽 진행.
2. 같으면 남은 경로가 짧은 쪽 진행.
3. 같으면 robotId 해시 (v1 과 동일, 마지막 키).

한 번 정하면 구간이 끝날 때까지 안 뒤집는다 (v0 sticky 시드와 같은 이유).

대기 상한: 예) 상대 5초 호라이즌 + α. 넘으면 L3 또는 L4.

### L2 — 교행

대기 비용이 커도, 충돌 지점의 **가로 여유**가 `2 × 로봇폭 + TRAFFIC_SEP` 보다 크면
ORCA(또는 등가 횡변위)로 경로를 1 반경 정도만 민다.
새 전역 A* 금지. 목표 헤딩은 유지.

여유 폭이 안 되면 L2 스킵. 그건 복도 후보 → 사용자는 `corridor` 를 그리는 게 맞다.
응급으로는 L1 대기가 포탈 역할을 한다 (충돌 지점 앞에서 섬).

### L3 — 작은 우회

L1 대기 시간이 `T_wait` 를 넘고, 우회 추가 길이가 `v * T_wait * λ` (λ≈1.2) 보다 **짧을** 때만
시공간 A* / 우선순위 재계획.

상대 플랜 전체를 벽으로 쓰지 않는다. `(cell, t ± τ)` 만 막는다.
그래서 “상대가 지나간 뒤 그 길을 그대로 씀”이 가능해진다.

### L4 — FMS

두 대가 서로 다른 sticky 결론을 내거나, L1~L3 이 수 초째 진동하면
FMS가 **한 대에 delay**, 다른 대에 proceed. 좌표 없음.

그래도 기하 우회가 필요한데 로봇 A*가 맵을 한 바퀴 돌면
일시 prefer 힌트 ([`04_fms_hints.md`](./04_fms_hints.md)).

### L5 — 안전망

바디 디스크에 닿으면 정지. 존 미배치 복도에서 둘이 들어간 뒤에만 trail 후진 (v1 VACATE).
로그에 `missing_corridor_zone?` 를 남겨 사용자가 존을 그리게 한다.

## 3. 의사코드 (개념)

```
onFleetLocalPlans(peers):
  if inside_user_mutex_zone: return  // 존 모듈

  mine = spacetime(localPlan)
  if not overlap(mine, peers):
    follow(path)  // 감속 해제
    return

  winner = stickyYield(me, peers)
  gap = lateralClearance(conflictPoint)

  if winner == me:
    follow(path)
  else if canWaitAlongPath(mine, peers):
    holdOrSlow(path)                 // L1
  else if gap >= PASS_WIDTH:
    orcaSidestep(path)               // L2
  else if detourCheaperThanWait():
    spacetimeReplan()                // L3
  else:
    hold(path)                       // FMS L4 를 기다림
```

## 4. 시나리오로 읽는 스택

| 장면 | 기대 | 층 |
|------|------|----|
| 교차로, 폭 충분 | 한 대 1~2초 대기, 경로는 직선 | L1 |
| 넓은 홀 정면 | 서로 살짝 비껴 통과 | L2 |
| 상대가 내 앞을 5초 내 가로지름 | 그 시각만 비우고 같은 길 | L1 또는 L3 (짧은) |
| 상대가 목표에 앉아 있음 | 옆에서 대기, 떠나면 진짜 목표로 | L1 + 목표 재시도 (v1 수정분) |
| 좁은 복도 정면, 존 없음 | 포탈처럼 앞에서 대기. 후진은 최후 | L1 → L5. 존 그리기 권고 |
| 좁은 복도 + 사용자 존 | 이 스택 밖에서 토큰 | 존 모듈 |

---

## 5. v1 에서 가져올 것 / 버릴 것

가져올 것: 로컬 플랜 브로드캐스트, sticky 패자, 목표 미도달 시 hold, 정책 스위치 팩토리.

버릴 것: 플랜을 정적 원 장애물로 넣는 전역 A*, 우회 실패 = 곧 VACATE, 열린 맵에서 FMS 교착 2초.

---

## 6. 아직 고르지 않은 파라미터

문서 확정, 코드 아님.

- `LOOKAHEAD_S` 유지(5) vs 시공간만 3초.
- `T_wait` 상한.
- `PASS_WIDTH` = 2×폭 + `TRAFFIC_SEP` 인지.
- sticky 를 FMS만 계산할지, 로봇도 같은 함수를 복제할지 (결정론이면 복제 가능).

구현 착수 때 `07` 격으로 옮긴다.
