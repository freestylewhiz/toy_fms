# 실기 연동과 주행 모드

상태: 논의 후보. 현재 가상 로봇과 자체 gRPC 동작을 기준으로 범위를 정한다.

## 주행 방식

자유 주행·그래프 주행 지원 능력(capabilities), 작업 요청(requested), 실제 상태(current)를 구분할지 결정한다.
경로 계획 주체 robot/fms/hybrid와 navigationMode를 별개로 다룬다.
작업이 없고 정지한 상태에서만 모드를 전환하는 안이 있으나 주행 중 전환 정책은 미확정이다.
그래프 단계·버전과 node/edge 예약은 [FMS 논의](../../fms/backlog/maps-and-graph.md)와 함께 정한다.

## VDA·이기종 어댑터

대상 제조사·장비·표준 버전·지원 주문/액션을 정한 후 공식 사양을 확인한다.
기존 편집 속성과 공통 상태 모델을 표준 필드에 무조건 일대일 대응시키지 않는다.
로봇이 보고하는 운용 모드와 사용자 FMS 운영 참여 설정은 다른 의미다.
프로토콜 원본 보존과 내부 상태 변환의 책임을 나눌지 논의한다.

## 물리 안전과 관측

시뮬레이터의 상대 위치 전달을 실제 센서 기반 판단으로 대체할 범위를 정한다.
오프라인·운영 제외 로봇이 이동한 경우 장애물 위치 해소,
로컬 정지·통신 장애·취소 확인·재활성화 검증을 실기 시나리오로 정의해야 한다.
