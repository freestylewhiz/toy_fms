# 자유 공간 트래픽 확장

상태: 미구현 제안. 과거 v2 설계를 현행 정책으로 취급하지 않는다.

목표 후보는 상대의 미래 경로 전체를 정적 벽으로 간주해 생기는 과도한 우회·후진을 줄이는 것이다.
검토 순서는 경로를 유지하는 감속·대기, 여유 폭이 있을 때 짧은 교행,
작은 우회, FMS 지연 중재다. ORCA나 시공간 계획의 채택은 아직 구현 확정이 아니다.

## 결정할 사항

- 단기 경로에 시간·불확실성을 어떻게 표현할 것인가?
- 양보 결정 주체는 FMS인가 로봇인가? 선택이 반복해서 뒤집히지 않도록 어떻게 유지할 것인가?
- 대기 상한·여유 폭·교착 판정·후퇴 조건을 어떤 시나리오로 검증할 것인가?
- 용량 존 내부와 자유 공간 제어를 어떻게 전환할 것인가?

일시 prefer 힌트는 추가 후보다. 채택한다면 사용자 영속 존과 분리하고
유효 시간·충돌 종료·취소 시 제거한다. 로봇이 안전상 거절할 수 있는 비용 힌트로 다룰지 합의해야 한다.
임의 TTL이나 우선순위 수치를 현행 상수로 복사하지 않는다.

검증 후보: 교차로 대기, 넓은 홀 교행, 목표를 점유한 로봇, 존 없는 좁은 복도, 정원 존과의 전환.
관련: PILOT-10, [현재 트래픽](../current/traffic.md).
