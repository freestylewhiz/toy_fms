# 트래픽 컨트롤 v1 — 로컬 패스 동기화

`TRAFFIC_POLICY_ID = "local_plan_v1"` 일 때 활성. v0(`corridor_lease_v0`)과 **같은 배선** 위에서 갈아끼운다.

## 한 줄

> 로봇은 앞으로 약 5초의 로컬 경로를 FMS에 올리고, FMS는 같은 맵의 로봇들에게 위치+로컬 플랜을 동기화한다.
> 평소엔 각 로봇이 스스로 달린다. FMS는 **로컬 플랜이 겹쳐 교착일 때만** 우회 기회를 주고, 우회가 없으면 **지나온 길을 되돌린다**.

## v0 대비

| | v0 회랑 임대 | v1 로컬 플랜 |
|---|---|---|
| 평시 | FMS가 공간 승인 (신호등) | 로봇 자율 주행 |
| 상대 정보 | 원칙상 경로 비공유 (시뮬만 pose) | **5초 로컬 플랜을 FMS가 브로드캐스트** |
| 교착 | STOP/PARTIAL + E2/E3 | 겹침 감지 → REROUTE → 실패 시 궤적 후퇴 |
| 안전 | I1/I2 회랑 disjoint | 예측 occupancy + 근접 정지. 회랑 강제 아님 |

v1은 P1을 **의도적으로 완화**한다. 로봇이 받는 것은 상대의 **짧은 로컬 플랜**이지 목적지/전역 경로는 아니다.
