# 맵 노이즈 정제 실험 도구

`map_noise_cleanup.ts`는 1st Floor 이미지로 검토한 규칙 기반 정제 로직이다.
알고리즘 버전: **experimental-v1**. Bun 내장 기능만 사용하며 추가 패키지가 필요 없다.

## 실행

저장소 루트에서 기본 실험을 재현한다.

```bash
bun run resources/tools/map_noise_cleanup.ts
```

입력 파일과 출력 디렉터리를 지정할 수도 있다.

```bash
bun run resources/tools/map_noise_cleanup.ts resources/maps/1st_floor.png /tmp/map-noise-result
bun run resources/tools/map_noise_cleanup.ts --help
```

- 기본 입력: `resources/maps/1st_floor.png`
- 기본 출력: `share/map-noise-experiment/`
- 기본 경로는 스크립트 위치 기준, 직접 입력한 상대 경로는 실행 디렉터리 기준이다.
- 기존 `bun run scripts/experiment_map_noise.ts` 명령도 이 도구로 연결된다.
- 입력은 **비인터레이스 8비트 RGBA PNG**를 지원한다. RGB·팔레트·그레이스케일 PNG는 직접 지원하지 않는다.
- 같은 출력 디렉터리로 재실행하면 결과 파일을 갱신한다. 다른 맵의 결과를 보관하려면 출력 디렉터리를 구분한다.

## 결과

| 파일 | 내용 |
| --- | --- |
| `<입력명>.cleaned.png` | 선택한 장애물 픽셀과 주변 테두리를 흰색으로 변경한 정제본 |
| `<입력명>.removals.png` | 원본 위에 변경한 픽셀만 빨간색으로 표시 |
| `metrics.json` | 알고리즘 버전, 입력 경로, 임계값, 후보 ID·면적·형상과 변경 픽셀 수 |
| `1st_floor.detail.png` | 기본 원본을 사용할 때만 생성하는 확대 비교. 왼쪽 원본, 오른쪽 정제본 |

확대 비교의 좌표 `(225,410)..(330,500)`는 출력 설명용이며 **검출 범위를 제한하지 않는다**.
전체 맵에 동일한 규칙을 적용한다. 원본 PNG, occupancy binary, FMS 설정과 DB는 수정하지 않는다.

## 처리 순서와 현재 기준

1. RGB 평균 밝기 100 미만을 장애물로 분리하고 8방향 연결 요소를 추출한다.
2. 면적 100px 이하, 최대 가로/세로 22px 이하인 조각을 후보로 삼는다.
3. 면적 32px 이하 또는 채움 비율 0.75 이하 또는 가로세로 비율 1.6 이상이면 형태 조건을 만족한다.
4. 후보 사각 경계를 바깥으로 4px 확장한 테두리에서 밝기 230 이상인 픽셀 비율이 60% 이상이어야 한다.
5. 면적 101px 이상인 장애물과 실제 픽셀 간 거리 4px 이내의 후보는 보존한다.
6. 밝기 120~220의 회색 연결 요소 중 128px 이상을 보호하고 주변 1px도 보호한다. 후보가 이 보호 마스크에서 2px 이내이면 제외한다.
7. 후보 사이의 체비쇼프 거리(가로·세로 차이 중 큰 값)가 20px 이내인 이웃을 찾는다. 자기 자신 포함 4개 이상이고 해당 국소 묶음의 최대 가로/세로가 80px 이하이면 선택한다.
8. 선택한 검은 조각과 그 조각에서 2px 이내인 밝기 100~229 테두리를 정리한다. 보호된 회색 영역 주변과 남길 장애물의 바로 옆 픽셀은 보존한다. 테두리 확장에는 원래 선택한 검은 픽셀만 사용한다.
9. PNG와 분석 정보를 저장한다.

주요 조정값은 코드 상단 `THRESHOLDS`에 있다. 픽셀 단위로 조정한 실험 설정이므로 다른 해상도·축척의 맵에는 재검토가 필요하다.
`perimeter`는 상하좌우 노출 변의 합이며, 현재 선택에는 면적·채움 비율·종횡비를 사용한다.
군집은 겹칠 수 있는 국소 이웃 묶음이며 DBSCAN의 구현은 아니다. `cluster`는 마지막으로 매칭된 국소 묶음 ID이다.

- 실행 시간 참고: Bun 1.3.13 / Xeon Gold 6154에서 기존 실험 진입점 10회 평균 0.775초. 시작·분석·PNG/JSON 저장 포함, 파일 캐시와 부하에 따라 달라진다.

연결 요소·형상 분석·거리 기반 이웃 계산은 기존 영상처리 기법이다. 이들을 결합한 노이즈 판정은 이 이미지에 맞춘 **휴리스틱**이며 실제 장애물과 노이즈를 구분하는 정확도가 검증된 모델은 아니다.
일부 옅은 윤곽이나 고립된 조각은 남는다. 결과를 주행에 적용하려면 원본과 비교 검토하고 occupancy·inflated 재생성, 맵 버전 관리와 서버·로봇 동기화를 별도로 구현해야 한다.
